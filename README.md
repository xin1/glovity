# Glovity

Glovity 是一个面向数据手套、手部姿态估计与触觉交互的研发仓库，包含视觉定位、IMU 姿态解算、坐标系对齐、机械手控制和振动反馈等实验代码与学习记录。

## 目录说明

- `code/`：各类可运行程序、嵌入式固件、硬件 SDK 和调试工具。
- `note/`：项目实践、算法学习和阶段工作总结。
- `image/`：项目文档使用的图片资源。

`code/` 中的主要模块包括：

- `ARU8113/`、`Vision_pnp_marker/`：视觉标记识别与 PnP 位姿估计。
- `Frame_alignment/`：手套、NOKOV 与其他设备间的坐标系对齐。
- `IMU*/`：多种 IMU 的采集、校准、姿态融合与可视化。
- `Motor_Erm/`：ERM 振动马达控制实验。
- `Motor_Lra_web/`：LRA 触觉反馈、机械手控制与 Web 控制台。

## 使用说明

各模块的硬件、依赖和启动方式不同，请进入对应目录查看其 `README.md`。建议按需创建独立的 Python、Arduino、STM32 或 ROS 2 开发环境。

`Motor_Lra_web/linkerhand/ros2/` 是约 2 GB 的本地 ROS 2 环境，未纳入仓库；需要使用时请根据模块说明在本地重新配置。
