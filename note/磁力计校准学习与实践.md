# 磁力计校准学习记录

记录日期：2026-09-07  
项目硬件：MPU6500/MPU9250 + AK8963  
项目目标：完成三轴磁力计硬铁、软铁校准，将校准参数接入 Arduino 九轴数据流，并验证校准质量和姿态融合表现。

## 1. 为什么磁力计需要校准

三轴磁力计测量的是磁场向量：

```text
m = [mx, my, mz]
```

在同一地点且周围磁场稳定时，无论传感器朝向如何变化，地磁场向量的方向会改变，但模长应基本不变。因此，将设备缓慢旋转并采集各方向数据，理想点云应该是一个以原点为中心的球面。

实际数据通常表现为偏心、拉伸、压缩甚至倾斜的椭球，主要来源于硬铁误差和软铁误差。

### 1.1 硬铁误差

硬铁误差是设备周围近似固定的附加磁场，例如永磁体、扬声器、电机、磁性螺丝和持续通电的导线。它主要使整个点云偏离原点：

\[
m_{measured}=m_{true}+b
\]

其中 \(b\) 是三轴硬铁偏置。修正方法是从原始测量值中减去该偏置。

### 1.2 软铁误差

软铁误差来自铁磁材料、结构件、PCB和传感器三轴灵敏度差异。它会改变磁场的尺度与方向关系，把理想球面变成椭球：

\[
m_{measured}=A m_{true}+b
\]

软铁误差不仅可能造成三个轴缩放不同，也可能造成轴间耦合，所以正式程序使用完整的 `3×3` 矩阵，而不只是三个独立缩放系数。

## 2. 本项目采用的校准模型

项目统一采用列向量公式：

\[
m_{cal}=M(m_{raw}-b)
\]

对应代码和配置文件中的表达为：

```text
calibrated = soft_iron_matrix @ (raw - hard_iron_offset)
```

其中：

- `raw`：经过 AK8963 厂家灵敏度修正、但尚未经过环境校准的三轴数据；
- `hard_iron_offset`：硬铁偏置 \(b\)；
- `soft_iron_matrix`：完整 `3×3` 软铁修正矩阵 \(M\)；
- `calibrated`：中心接近原点、模长更加一致的校准结果。

椭球校准负责修正偏置、比例和轴间耦合，但不能独立确定磁力计与加速度计之间的安装方向，也不能判断磁北和磁南的绝对极性。

## 3. 简单校准与正式校准的区别

项目中保留了两个算法实现。

### 3.1 简单校准

`simple_calibrate_magnetometer.py` 根据各轴最大值和最小值估算中心，并分别缩放 X、Y、Z 三个轴。

优点：

- 算法直观；
- 计算速度快；
- 适合学习基本原理。

局限：

- 只能处理三轴独立偏置和缩放；
- 不能很好处理倾斜椭球；
- 不能处理完整轴间耦合；
- 容易受极值异常点影响。

### 3.2 正式完整 `3×3` 校准

`calibrate_magnetometer.py` 是日常应使用的正式程序，主要步骤为：

1. 读取三列磁力计数据并检查有效样本数；
2. 对数据进行位置和尺度归一化，提高数值稳定性；
3. 使用代数椭球拟合提供初始值；
4. 将二次型约束为正定矩阵，避免产生无效双曲面；
5. 使用 Cauchy 稳健损失进行非线性拟合；
6. 使用中位数绝对偏差（MAD）识别异常点；
7. 只使用内点进行第二次精修；
8. 对正定二次型进行特征值分解，生成对称完整 `3×3` 修正矩阵；
9. 计算质量指标并输出 JSON、报告、校准后 CSV 和 Arduino 头文件。

异常点判定规则为：

```text
abs(radial residual - median) <= max(4.5 × MAD_sigma, 2.5%)
```

这使少量磁干扰或串口异常数据不会主导整个拟合结果。

## 4. 数据采集方式

### 4.1 Arduino采集模式

磁力计原始采集草图为：

```text
arduino/mpu9250_ak8963_raw/mpu9250_ak8963_raw.ino
```

重新校准时必须设置：

```cpp
constexpr bool APPLY_MAG_CALIBRATION = false;
```

此时 Arduino 输出的数据已经应用 AK8963 芯片内部的厂家灵敏度系数，但没有应用硬铁和软铁校准。

如果在 `APPLY_MAG_CALIBRATION = true` 时采集校准输入，就会对已经校准过的数据再次拟合，形成二次校准，结果可能失真。

### 4.2 采样率

AK8963 当前设置为：

```text
16位输出 + 连续测量模式2（寄存器值 0x16）
```

有效磁力计采样率约为 `100 Hz`。提高串口波特率、I²C速度或MPU6500采样率，都不能突破AK8963本身约100 Hz的有效输出上限。

按100 Hz估算：

| 采集时间 | 约采样点数 |
|---:|---:|
| 10秒 | 1000 |
| 20秒 | 2000 |
| 30秒 | 3000 |
| 45秒 | 4500 |
| 60秒 | 6000 |
| 80秒 | 8000 |

大量相邻点并不等于高质量校准。方向覆盖通常比单纯增加采样点数更重要。

### 4.3 正确的转动方法

采集时应缓慢转动整套最终装配好的设备，并做到：

- 覆盖正放、倒放、左侧、右侧、前侧、后侧和多个斜向；
- 围绕 X、Y、Z 三个方向变化，不只在桌面水平旋转；
- 尽量覆盖完整球面和全部八分体；
- 远离手机、扬声器、磁吸工具、电机、大电流导线和金属桌架；
- 保持USB线、PCB、螺丝和其他结构的相对位置与最终使用状态一致；
- 平稳转动，避免敲击、剧烈晃动和快速改变与外部磁性物体的距离。

## 6. 质量指标的含义

### 6.1 内点比例

内点比例表示有多少样本符合最终椭球。比例过低通常意味着动态磁干扰较多，或者采集过程改变了传感器与磁性结构的相对位置。

### 6.2 校准后半径 CV

CV为标准差与平均值之比：

\[
CV=\frac{\sigma_r}{\bar r}
\]

它反映校准后球面半径的一致程度。越低说明点云越接近球面。本项目将 `5%` 设为通过阈值。

### 6.3 P95绝对相对误差

P95表示95%的内点，其半径相对误差不超过该数值。它比只看平均误差更能反映较差方向上的表现。本项目要求不超过 `10%`。

### 6.4 方向覆盖条件数

该指标衡量采样方向是否均匀覆盖三维空间。越接近1越均匀；数值很大通常意味着数据集中在平面、圆环或少数方向。本项目要求不超过10，并要求八个空间八分体全部出现数据。

### 6.5 校准矩阵条件数

条件数过大表示某些方向需要极强的放大或压缩，可能说明数据退化、传感器环境异常或拟合不可靠。本项目要求小于5。

## 8. 可视化HTML的作用

运行：

```powershell
python .\mag_calibration\interactive_calibration_visualization.py
```

会生成 `data/calibration_interactive.html`。该文件只用于检查，不参与Arduino运行或姿态融合。

检查重点：

- 原始点云是否是偏心椭球；
- 校准后点云是否以原点为中心；
- 校准后是否接近球面；
- 数据是否覆盖所有方向；
- 是否存在明显离群点、空洞或局部密集；

## 9. Arduino中的应用

九轴数据流草图调用：

```cpp
applyMagCalibration(adjustedX, adjustedY, adjustedZ, mx, my, mz);
```

Arduino首先读取AK8963原始值，再应用厂家灵敏度系数，最后执行：

```text
去除硬铁偏置 → 完整3×3软铁矩阵 → 输出校准后磁场
```

实时Python程序再使用默认轴映射：

```text
y,-x,-z
```

所以当前完整链路为：

```text
AK8963原始值
  → 厂家ASA灵敏度修正
  → 硬铁偏置修正
  → 完整3×3软铁修正
  → y,-x,-z轴映射
  → Mahony九轴融合
  → Roll/Pitch/Yaw和3D姿态
```

## 10. 与陀螺仪和Mahony融合的关系

磁力计主要为Yaw提供长期方向参考。陀螺仪负责快速动态响应，加速度计主要约束Roll和Pitch。

当前陀螺仪配置为：

```text
量程：±2000 °/s
换算：16.4 LSB/(°/s)
```

Arduino寄存器必须设置为 `GYRO_CONFIG = 0x18`，Python必须使用 `gyro_raw / 16.4`。两侧不一致会直接造成角速度比例错误。该量程修改与磁力计椭球参数相互独立，不要求因为改变陀螺仪量程而重新校准磁力计。

Mahony参数：

- `Kp`：根据当前加速度计、磁力计误差进行即时纠偏；
- `Ki`：累积长期误差，用于补偿剩余陀螺仪零偏；
- 启动零偏：设备静止时对陀螺仪求平均，运行中从每个角速度样本中减去。

如果磁力计方向错误，增大 `Kp` 可能让错误的Yaw纠偏更强；`Ki`过大则可能把错误长期累积，产生缓慢自转。因此不能用调节 `Kp/Ki` 代替正确的校准和轴映射。

## 11. 坐标对齐实验得到的经验

项目曾尝试通过多个静止姿态下“重力与地磁夹角恒定”的条件，拟合磁力计到加速度计的坐标对齐矩阵。

该实验暴露出两个问题：

1. 仅凭静止的加速度和磁场夹角，不能区分磁北与磁南的整体极性；
2. 对齐结果或极性与Mahony坐标约定不一致时，磁场纠偏会持续推动Yaw，表现为设备静止但模型仍绕Z轴转动。

由于实际融合效果不稳定，该对齐程序和自动加载逻辑已经删除。当前项目恢复为经过实际使用验证的固定映射 `y,-x,-z`。

这次实验说明：

- 椭球拟合结果为PASS，不等于坐标轴方向一定正确；
- 数学上正交且行列式为 `+1` 的矩阵，也不保证符合具体芯片输出极性和融合代码约定；
- 坐标系修改必须同时检查加速度计、陀螺仪、磁力计和四元数定义；
- 每次只改变一个因素，并保留可回退版本，更容易定位问题。

## 13. 校准时间与成功率测试方案

如果要研究最少需要采集多长时间，可以分别测试：

```text
10秒、20秒、30秒、45秒、60秒、80秒
```

每个时长建议重复至少10次，并统一以下条件：

- 使用同一块硬件和装配状态；
- 使用相同位置和相近的旋转动作；
- 使用相同的自动质量阈值；
- 每次都从原始未校准数据开始；
- 记录是否PASS以及主要质量指标。

成功率定义为：

\[
成功率=\frac{PASS次数}{总测试次数}\times100\%
\]

建议记录表：

| 试验编号 | 时长/s | 样本数 | 内点率 | 校准后CV | P95误差 | 覆盖条件数 | PASS/FAIL | 备注 |
|---|---:|---:|---:|---:|---:|---:|---|---|
| 1 | 10 |  |  |  |  |  |  |  |
| 2 | 20 |  |  |  |  |  |  |  |
| 3 | 30 |  |  |  |  |  |  |  |

需要注意：较短时间失败可能是因为来不及完成三维方向覆盖，而不一定是样本数量不足。可以另外使用同一份高质量完整数据进行随机抽样，以区分“点数不足”和“动作覆盖不足”两种因素。

## 14. 常见问题与判断方法

### 校准结果FAIL

优先检查：

- 是否覆盖全部八分体；
- 是否只绕一个轴旋转；
- 是否靠近动态磁干扰；
- 是否错误地采集了已经校准的数据；
- 是否更换了传感器、螺丝、外壳或线缆位置。

### 校准后仍然缓慢漂移

椭球校准只能改善磁场数据，不能代替陀螺仪零偏估计和坐标轴检查。还应确认：

- 启动前三秒是否平稳放置并完全静止；如果此时移动，错误的陀螺仪均值会被当作零偏，随后持续参与积分；
- Arduino和Python陀螺仪量程是否都为 `±2000 °/s / 16.4`；
- `y,-x,-z` 是否仍符合当前安装；
- 磁场模长是否稳定；
- `Ki`是否累积了来自错误磁场方向或动态干扰的修正。

### 快速转动后回正很慢

可能原因包括：

- 陀螺仪量程饱和导致真实转角丢失；
- 快速运动时加速度不再只代表重力，暂时不能可靠纠偏；
- 磁场受到运动中的电流或金属结构影响；
- 磁力计低通或融合纠偏带宽较低；
- 融合器积分项累积了此前的误差。

早期 `±500 °/s` 实测日志中，三个陀螺轴都触及约 `±500 °/s` 的量程上限，多轴合成角速度最高达到 `848.8 °/s`；快速动作产生的加速度最高达到 `5.46 g`，其中555个样本落在融合器允许的加速度模长范围之外。这说明当时的慢回正同时受到“陀螺仪削顶”和“动态加速度暂时不可用”的影响。

当前采用 `±2000 °/s` 是为了降低快速转动时陀螺仪削顶的概率，但量程增大也会降低低速分辨率。

### `Kp`和`Ki`如何影响表现

- `Kp`太小：当前姿态误差修正较慢，表现为回正慢；
- `Kp`太大：加速度或磁场噪声会被强烈引入，容易抖动；
- `Ki`太小：长期陀螺仪零偏修正较弱，可能出现缓慢漂移；
- `Ki`太大：错误会被持续累积，可能出现过冲、振荡或不稳定。

调参只能改变纠偏速度和噪声敏感度，不能修复错误的量程换算、磁力计校准或轴映射。

## 15. 阶段性结论

本项目已经形成一套可重复的磁力计校准流程：

```text
原始数据采集
  → 稳健正定完整3×3椭球拟合
  → 异常点筛选和内点精修
  → 自动质量检查
  → JSON/报告/CSV/Arduino头文件输出
  → 交互式3D验证
  → Arduino九轴数据流
  → Python Mahony姿态融合
```

当前8927点结果通过全部自动检查。后续工作的重点不是继续提高AK8963采样频率，而是优化采集动作的一致性、三维方向覆盖和磁场环境，并通过多次定时实验统计校准成功率。
