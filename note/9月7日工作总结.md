**失败主要原因：磁场不稳定、磁性干扰（过于靠近电脑）**

失败其他原因：

| 检查项                          | 当前阈值       | 检查内容                                     | 常见失败原因                                                 |
| ------------------------------- | -------------- | -------------------------------------------- | ------------------------------------------------------------ |
| `enough_samples`                | ≥ 500 点       | 有效数据总量是否足够                         | 采集时间太短、串口丢包、CSV 格式不正确、存在大量无法解析的行 |
| `enough_inliers`                | 内点比例 ≥ 90% | 稳健拟合后，正常点是否占绝大多数             | 周围磁场变化、经过磁铁/电机/钢材、线缆摆动、传感器读数突变、移动范围太大 |
| `all_octants_covered`           | 8/8 个八分体   | 三维空间八个方向区域是否都采集到了           | 只绕 Z 轴水平旋转、没有翻转设备、某些正负轴组合没有到达      |
| `direction_coverage_reasonable` | 条件数 ≤ 10    | 数据在球面上的分布是否相对均匀               | 点集中在一圈、一个平面或少数方向；虽然可能碰到了八个区域，但各区域数量严重不均 |
| `radius_cv_below_5_percent`     | CV ≤ 5%        | 校准后球面“厚不厚”，半径标准差÷平均半径      | 磁场不稳定、磁性干扰、软硬铁模型不能解释数据、异常点较多、采集位置发生移动 |
| `p95_error_below_10_percent`    | P95 ≤ 10%      | 95% 的内点，其半径误差是否小于目标半径的 10% | 局部方向误差大、存在成段干扰、球面出现凸起/凹陷、仍有较多异常点未被剔除 |
| `matrix_condition_below_5`      | 条件数 ≤ 5     | 校准矩阵最大与最小缩放比例是否合理           | 方向覆盖不足导致拟合退化、数据近似共面、某一轴范围太小；也可能是设备附近存在非常严重的软铁干扰 |

可视化的核心好处是：把原本只能“凭感觉转动”的校准过程，变成可以实时观察和有针对性补采的过程。

主要作用包括：

- 判断方向是否覆盖完整
  右侧红、黄、绿方向点可以直接显示哪些角度没有转到，避免只绕某一个轴旋转。
- 缩短采集时间
  不需要盲目采集固定的 60～120 秒。方向覆盖充分后就可以结束，有时约 20～30 秒也能获得合格结果。
- 提高校准成功率
  可以及时补充缺失方向，降低八分体覆盖不足、方向分布不均和矩阵条件数过大的概率。
- 及时发现磁场干扰
  左侧原始散点如果突然出现向外延伸的长线、孤立点或整体膨胀，通常说明设备靠近了电脑、金属、电机或其他磁性物体。
- 判断动作是否有效
  如果持续转动，但右侧仍有大量红点，说明动作可能集中在同一平面，需要增加翻滚和俯仰方向。
- 便于解释失败原因
  最终交互式 HTML 可以对比校准前后的点云：正常情况下，原始椭球经过校准后应变成以原点为中心、半径较一致的球面。
