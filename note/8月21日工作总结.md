## 1. 单端信号与差分信号

### 1.1 单端信号

单端信号是：V_{signal}=V_{线}-V_{GND}

也就是用一根信号线相对于 GND 的电压来表示信息。

优点：

- 电路简单
- 成本低
- 适合短距离、干扰较小的场景

缺点：

- 容易受到地线噪声影响
- 抗共模干扰能力较弱
- 微弱信号更容易被噪声淹没

### 1.2 差分信号是什么

**差分信号（Differential Signal）**使用两根信号线之间的电压差来表示信息，而不是看某一根线相对于地（GND）的电压。

公式：V=V+-V-

例如：

| 状态   |   V+ |   V- | 差分电压 |
| ------ | ---: | ---: | -------: |
| 状态 1 |  3 V |  1 V |     +2 V |
| 状态 0 |  1 V |  3 V |     -2 V |

#### 差分信号的主要优点

抗干扰能力强。

假设外界干扰同时让两根线增加 0.5 V：

(3+0.5)-(1+0.5)=2V

两根线同时受到的干扰会在相减时被抵消，这类干扰称为**共模干扰**。

#### 常见差分接口

- CAN：CAN_H / CAN_L
- RS485：A / B
- USB：D+ / D-
- Ethernet：差分线对

### 1.3 单端转差分

使用单端转差分转换电路即可，这种情况是因为信号频率很高或者对于信号质量要求比较高的的场合，单端信号不能满足要求，所以要换成差分的。

### 1.5 共模信号与差模信号

共模信号和差模信号这两个概念多用于差分电路，如（差分放大电路），**单独一根信号线没法谈共模差模，两根信号线才会有差模信号共模信号的说法**，分别描述了这两根信号线电位与地线电位之差（共模）和这两根信号线电位之差（差模），这里和单端信号和差分信号有一些类似。

- 差模信号计算公式：(V1-V2）/2
- 共模信号计算公式：（V1+V2）/2

 **共模干扰和差模干扰**

共模干扰就是指两条信号线与地之间的干扰信号，差模干扰就是两条信号线间的干扰信号。**信号都是差模形式的，所有的干扰都是抗共模干扰的**。

1.**传导干扰（传导噪声）**。主要就是地端电位不稳定带来干扰，地端电位如果发生抖动，那地端与信号线间的电压就会不稳定也就是共模电压不稳定，即产生了共模干扰。若两根线上的共模干扰电压不一致则还会使这两根信号线的差值发生抖动，引起差模干扰。我们常将信号线做成双绞线（差分输入）的原因就是让两根信号线的空间位置相对接近使它俩的共模干扰电压一致从而尽可能的消除了差模干扰，减小误差。

2.**空间耦合干扰（辐射噪声）**。空间中变化的电磁场在信号线上产生压降带来共模和差模干扰。

**共模抑制比**

用来说明差分放大电路抑制共模信号及放大差模信号的能力，常用共模抑制比作为一项技术指标来衡量，其定义为放大器对差模信号的电压放大倍数Aud与对共模信号的电压放大倍数Auc之比，称为共模抑制比。

 **差模信号与共模信号的转化**

传输线中不仅存在传播信息的差模信号，还有不传播信息的共模信号，理想情况是不存在相互转化的，但是理想很丰满，现实很骨感。

差模信号与共模信号的转化是由于差分传输线不对称造成的，造成不对称的原因很多，差分传输线的长度差像拐角、差分传输线由于刻蚀差异造成传输线特性阻抗不同、两个传输线的差异性耦合、临近效应、终端差异，弯曲等等都可能是造成差模信号与共模信号的转化。

这种转化我们可以理解为两条传输线的延迟是不同的，当信号在传输线上传播由于到达终端的延迟是不同的，一个早一些到达，这样就会产生相位差，将部分差模信号转化成共模信号。转化的为共模信号的多少由信号频率、传输线的长度、两条传输线上的信号时延差所决定的。

## 2. UART

**UART = Universal Asynchronous Receiver/Transmitter**

中文：

> 通用异步收发器

常见信号线：

- TX：发送
- RX：接收
- GND：地

典型特点：点对点通信,不需要独立时钟线,使用波特率约定通信速度

UART 常用于：

- MCU 串口调试
- GPS
- 蓝牙模块
- ESP32 与其他控制器通信

## 3. I²C

**I²C = Inter-Integrated Circuit**

是一种常见的板级串行通信总线。

核心特点：

> 两根信号线就可以让一个主控连接多个设备。

### 3.1 两根信号线

- SDA：Serial Data，数据线
- SCL：Serial Clock，时钟线

可以记：

> **SDA 管数据，SCL 管节奏。**

### 3.2 I²C 地址

多个设备可以共用 SDA 和 SCL，但每个设备通常有自己的地址，例如：

- IMU：0x68
- EEPROM：0x50
- 温度传感器：0x48

因此：

> SDA/SCL 可以共享，但设备地址一般不能冲突。

### 3.3 主机与从机

典型情况：

- ESP32：Master / Controller
- IMU：Slave / Target

主机负责：

- 发起通信
- 产生 SCL 时钟
- 指定要访问哪个设备

### 3.4 一次典型 I²C 读取

流程：

\[
START
\rightarrow 设备地址
\rightarrow ACK
\rightarrow 寄存器地址
\rightarrow 读取数据
\rightarrow STOP
\]

关键词：

- START：开始
- STOP：结束
- ACK：应答
- NACK：非应答

### 3.5 设备地址与寄存器地址

例如：

```cpp
Wire.beginTransmission(0x68);
Wire.write(0x20);
```

其中：

- `0x68`：设备地址
- `0x20`：设备内部寄存器地址

这两个概念不能混淆。

### 3.6 为什么 I²C 需要上拉电阻

SDA 和 SCL 通常使用 Open-Drain（开漏）结构。

设备主要负责：

> 把线路拉低。

高电平依靠上拉电阻拉到 3.3 V 或 5 V。

常见上拉电阻：

- 2.2 kΩ
- 4.7 kΩ
- 10 kΩ

实际取值需要结合总线速度、电容和设备数量。

### 3.7 常见速度

- 100 kHz：Standard Mode
- 400 kHz：Fast Mode
- 1 MHz：Fast-mode Plus
- 3.4 MHz：High-speed Mode

## 4. ECU

**ECU = Electronic Control Unit**

中文：

> 电子控制单元

可以把 ECU 理解为：

> 汽车内部负责某一类功能的小型控制器。

常见 ECU：

- 发动机 ECU
- ABS ECU
- 车身控制 ECU / BCM
- 安全气囊 ECU
- 电池管理系统 BMS

典型结构：

\[传感器 \rightarrow ECU \rightarrow 控制算法 \rightarrow 执行器]

汽车内部通常有很多 ECU，它们之间可以通过 CAN 总线通信。

因此：

\[\boxed{ECU = 控制器}]

\[\boxed{CAN = ECU之间常用的通信方式}\]

## 5. CAN

**CAN = Controller Area Network**

中文：

> 控制器局域网络

单词：

- Controller：控制器
- Area：区域
- Network：网络

CAN 主要用于多个控制器之间通信。

典型场景：

- 汽车
- 机器人
- 工业控制
- 电池系统
- 电机控制

### 5.1 CAN 信号线

CAN 使用一对差分线：

- CAN_H
- CAN_L

因此抗干扰能力较强。

### 5.2 CAN 的典型特点

- 多节点
- 差分传输
- 抗干扰强
- 支持仲裁
- 很适合实时控制
- 经典 CAN 单帧数据最多 8 字节
- 经典 CAN 常见最高速率约 1 Mbit/s

---

## 6. FDCAN / CAN FD

CAN FD 中：

**FD = Flexible Data-rate**

中文：

> 灵活数据速率

更标准的名称：

> CAN FD = Controller Area Network Flexible Data-Rate

FDCAN 常用于表示 MCU 中支持 CAN FD 的 CAN 外设，例如 STM32 中：

- FDCAN1
- FDCAN2

**CAN 与 CAN FD 对比**

| 项目         | Classic CAN | CAN FD               |
| ------------ | ----------- | -------------------- |
| 单帧数据长度 | 最多 8 字节 | 最多 64 字节         |
| 数据阶段速率 | 固定        | 可提高               |
| 数据量       | 较小        | 更大                 |
| 应用         | 普通控制    | 高数据量、高性能控制 |

记忆：

boxed{CAN FD = 更快、单帧能装更多数据的 CAN}

---

## 7. EtherCAT

**EtherCAT = Ethernet for Control Automation Technology**

中文可以理解为：

> 用于控制自动化的以太网技术

它是一种面向工业控制的**实时以太网通信技术**。

常见应用：

- 工业机器人
- 伺服电机
- PLC
- CNC
- 多轴运动控制
- 自动化产线

### 7.1 EtherCAT 的核心特点

关键词：

\[
\boxed{高速 + 实时 + 多设备同步}
\]

普通 Ethernet 更关注：

> 数据能否可靠传输。

EtherCAT 更关注：

> 数据不仅要传到，而且必须准时、同步地传到。

### 7.2 Processing on the Fly

EtherCAT 从站在数据帧经过时，可以直接读取或修改属于自己的数据，而不需要完整接收、重新打包再发送。

可以理解为：

```text
主站
 ↓
从站1 → 从站2 → 从站3 → 从站4
 ↑                       ↓
 └──────── 返回 ─────────┘
```

这使 EtherCAT 非常适合多个伺服轴同步控制。

### 7.3 CAN 与 EtherCAT 对比

| 项目     | CAN          | EtherCAT             |
| -------- | ------------ | -------------------- |
| 物理基础 | CAN 总线     | Ethernet             |
| 典型速率 | 约 1 Mbps    | 100 Mbps 级          |
| 数据量   | 较小         | 较大                 |
| 实时性   | 强           | 很强                 |
| 多轴同步 | 可以         | 非常适合             |
| 典型应用 | 汽车、控制器 | 工业机器人、伺服系统 |

## 8. 常见通信接口快速对比

| 接口     | 典型信号线           | 类型 | 典型用途              |
| -------- | -------------------- | ---- | --------------------- |
| UART     | TX、RX               | 单端 | 串口调试、模块通信    |
| I²C      | SDA、SCL             | 单端 | IMU、EEPROM、传感器   |
| SPI      | SCLK、MOSI、MISO、CS | 单端 | Flash、屏幕、ADC、IMU |
| RS485    | A、B                 | 差分 | 工业通信、长距离传输  |
| CAN      | CAN_H、CAN_L         | 差分 | 汽车、机器人、控制器  |
| USB      | D+、D-               | 差分 | PC 与外设             |
| Ethernet | 多对差分线           | 差分 | 网络通信              |
| EtherCAT | Ethernet 物理层      | 差分 | 实时工业控制          |
