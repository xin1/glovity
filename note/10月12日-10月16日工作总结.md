## 二、LRA 触觉控制台使用说明

| 模块       | 主要功能                                                     |
| ---------- | ------------------------------------------------------------ |
| 触觉采集   | 接收五指 `12 × 6` 压力矩阵                                   |
| 压力显示   | 显示 `0–15 N` 压力、曲线和峰值，实时曲线按 256 个层级平滑变化 |
| 空间解算   | 计算接触中心、合力方向和摩擦方向                             |
| 触觉识别   | 识别短振、长振、摩擦和碰撞                                   |
| 振动输出   | 压力同步映射到频率与振幅                                     |
| 参数设置   | 调整频率、振幅和反馈灵敏度                                   |
| F0 检测    | 检测当前指尖马达谐振频率                                     |
| 模拟测试   | 使用矩阵或曲线模拟连续压力输入                               |
| 机械手控制 | 控制 25 个关节和动作预设                                     |
| 软件标定   | 保存并恢复当前位置基准                                       |
| 状态诊断   | 显示 ROS2、ESP32 和串口状态                                  |
| 主题切换   | 支持日间与夜间界面                                           |

### 1. 启动与连接

1. 双击项目根目录的 `start-linkerhand-webui.bat`。

2. 浏览器会自动打开：

   `http://127.0.0.1:8765/`

3. 页面右上方显示 **“ROS2 数据流正常”** 后，即可查看 LinkerHand L20/L25 数据。

4. 如需控制 LRA，点击右侧 **“连接设备”**，选择 ESP32 对应的 COM 串口。

5. 等待设备状态显示就绪后再进行振动操作。

#### 五指总览

该换算属于实验标定，后续可以使用砝码重新校准。

### 3. 实机模式与模拟输入

#### 实机模式

<img width="715" height="457" alt="3fd99c4ca0ced33a9ccd69506820a87a" src="https://github.com/user-attachments/assets/dfc10c32-86bd-449d-ab47-692df7b9b78d" />  

按钮显示 **“实机模式”** 时：

- 页面读取 LinkerHand 指尖传感器数据。
- 压力变化会映射为振动频率和振幅。
- 选中的指尖决定单指曲线、矩阵和 F0 检测通道。
- 实机压力超过灵敏度阈值后，连接的 LRA 才会输出振动。

#### 模拟输入

<img width="953" height="492" alt="image" src="https://github.com/user-attachments/assets/814af23e-30d0-4e5e-8a2c-a11d7314e8e2" />

点击 **“实机模式”** 可切换为 **“模拟输入”**。

模拟输入支持两种操作：

##### 点击压力曲线

- 点击或上下拖动曲线区域模拟 `0–15 N` 压力。
- 越靠上压力越大，越靠下压力越小。
- 压力变化采用平滑缓动，不会突然跳变。
- 长按时曲线持续向前更新。
- 松开后立即停止。

##### 点击采样区

- 按住采样矩阵模拟触觉接触。
- 拖动可以改变接触位置和合力方向。
- 长按会持续输入，即使鼠标不移动也会继续更新。
- 松开后立即停止并归零。

连接 ESP32 和 LRA 后，模拟压力也可以实际驱动振动；未连接时仅进行界面预览。

### 4. 振动模式

右侧可以手动选择振动效果；当识别到相应模式时会亮对应识别指示灯。

#### 默认

- 按住多久振动多久。
- 压力同时控制频率和振幅。
- 轻压力输出较弱、频率较低。
- 重压力逐渐增加到当前设置的最大值。

#### 短振

- 单次触力时触发。
- 用于表现短促点击或点按反馈。
- 指示灯亮约 `0.5 秒`。

#### 长振

<img width="716" height="453" alt="d42f8e0bbbbcaf5c02a20612368f6ddd" src="https://github.com/user-attachments/assets/1d0c6ce7-f871-4487-9dc7-849fcb3033f8" />  

- 持续按压超过约 `0.5 秒`后识别。
- 按住期间持续亮灯和输出。

#### 摩擦

<img width="715" height="457" alt="3fd99c4ca0ced33a9ccd69506820a87a" src="https://github.com/user-attachments/assets/dfc10c32-86bd-449d-ab47-692df7b9b78d" />  

- 根据触觉压力中心的连续方向移动识别。
- 摩擦成立时，摩擦灯持续亮起。

#### 碰撞

<img width="716" height="458" alt="cb603dc5ceeea0e2fc517f7e5b379f8c" src="https://github.com/user-attachments/assets/eb8e6b24-8a13-49fc-911e-f2d97e554484" />  

- 初次接触压力超过约 `10 N` 时识别为碰撞。
- 碰撞灯亮约 `0.5 秒`。

#### 自定义模式

页面预留了三个自定义模式：

- 自定义 1
- 自定义 2
- 自定义 3

目前显示为“暂未定义”。

#### 立即停止

点击 **“立即停止”**：

- 立即停止当前 LRA 输出。
- 结束正在进行的模拟输入。
- 不会改变当前的实机/模拟输入模式。

### 5. 输出参数

#### 整体频率

- 可调范围：`0–400 Hz`
- 建议范围：`50–300 Hz`
- 建议区间在滑块中以浅色区域显示。

整体频率是压力达到最大映射时的频率上限。压力较小时，实际频率会相应降低。

#### 整体振幅

- 可调范围：`AMP 0–75`
- 建议范围：`AMP 25–47`

压力越大，实际 AMP 越接近设定上限；轻压力会使用较低输出，以拉开轻触和重压之间的差异。

修改后点击 **“应用到设备”**。

#### 反馈灵敏度

共有 `1–5` 档，默认使用：

- `5 · 高灵敏`

灵敏度越高，越小的压力变化也会产生反馈；灵敏度较低时，输出更稳定，但需要更大的压力变化。

### 6. 机械手运动控制

页面下方提供 LinkerHand L20/L25 的关节控制。

<img width="715" height="393" alt="3480f3233499edf1575868a2cc63daff" src="https://github.com/user-attachments/assets/8017229f-7491-48ce-bdf0-543afba3e81e" />  

#### 关节控制

- 共 `25` 个关节位置。
- 每个关节范围为 `0–255`。
- 调整滑块只修改目标位置。
- 点击 **“发送姿态”** 后才会真正控制机械手运动。
- 页面会读取实际位置并等待机械手到达目标。

#### 运动速度

可以选择：慢、正常、快

#### 内置动作

页面提供常用姿态预设，例如：张开、握拳、OK

选择预设后点击“发送姿态”执行。

#### 自定义动作

可以：

1. 调整各关节目标值。
2. 输入预设名称。
3. 点击“保存当前目标”。
4. 以后从自定义预设中载入或删除。

自定义预设保存在浏览器本地。

#### 软件基准标定

使用方法：

1. 让机械手保持在希望作为基准的位置。
2. 点击 **“读取当前位置”**。
3. 点击 **“用当前位置标定”**。
4. 后续可以点击 **“载入标定基准”**恢复。

这是软件基准，不会改写电机内部零位参数。

### 8. 状态和故障判断

#### ROS2 数据流正常

说明网页已经收到 LinkerHand 数据，可以查看触觉矩阵和关节状态。

#### 桥接已启动 · 等待 ROS2

说明网页服务已启动，但还没有收到机械手数据。需要检查：

- LinkerHand 驱动是否启动
- PCAN 是否正常
- 是否重复启动了驱动
- ROS2 触觉话题是否正在发布

#### ESP32 未连接

触觉数据仍可显示，但 LRA 只能预览，不能实际振动。

#### 串口日志

串口日志会显示：

- 网页发送的控制命令
- ESP32 返回信息
- 模式启动与停止
- F0 检测结果
- 设备错误或超时

出现问题时可先查看此区域。
