## 三、LRA 马达可视化测试系统

### 1. 各模式详细行为

| 模式 | 当前设置                                     |
| ---- | -------------------------------------------- |
| 短振 | 150Hz、最大AMP 38、60ms                      |
| 长振 | 130Hz、最大AMP 25、最短3秒，按住越久持续越久 |
| 锯齿 | 固定170Hz，五级渐强后快速断开                |
| 摩擦 | 50～170Hz，最大AMP 35，力度/高度越大频率越高 |
| 碰撞 | 达到6N才能触发，170Hz、AMP 33、28ms          |

#### 脉冲

- 触发压力：0.3～1.9N
- 按压时间：小于500ms
- 频率：150Hz
- 持续时间：60ms
- 默认振幅：AMP 38，约2.68Vpp
- 每次按下、松开只触发一次

#### 长振

- 触发压力：0.3～1.9N
- 长按判定时间：500ms
- 频率：130Hz
- 最短持续时间：3秒
- 默认振幅：AMP 25，约1.83Vpp
- 按住超过3秒后，按多久就持续多久
- 松开时未达到3秒，应继续运行至3秒结束

#### 锯齿

- 触发压力：2.0～3.9N
- 频率固定为实测F0：170Hz
- 默认峰值：AMP 42，约2.94Vpp
- 单轮波形：

| 阶段 | AMP  | 约Vpp   | 时间  |
| ---- | ---- | ------- | ----- |
| 1    | 25   | 1.83Vpp | 100ms |
| 2    | 29   | 2.09Vpp | 100ms |
| 3    | 33   | 2.35Vpp | 100ms |
| 4    | 37   | 2.61Vpp | 100ms |
| 5    | 42   | 2.94Vpp | 120ms |
| 释放 | 0    | 0V      | 40ms  |

总波形时间约1.12秒。用户修改峰值振幅后，其他阶段按比例缩放。

#### 摩擦

- 触发压力：4.0～5.9N
- 持续按压时连续输出
- 频率只与压力有关，与鼠标移动速度无关
- 压力4.0N对应50Hz
- 压力5.9N对应170Hz
- 中间采用线性映射：

```
频率 = 50 + (压力 - 4.0) ÷ 1.9 × 120
```

振幅也随压力线性增加：

```
振幅 = 最小振幅 + 压力比例 ×（最大振幅 - 最小振幅）
```

默认最大振幅为AMP 35，约2.48Vpp。压力退出摩擦区域或松开后立即停止。

#### 碰撞

- 触发阈值：≥6.0N
- 频率：170Hz
- 振幅：AMP 33，约2.35Vpp
- 持续时间：28ms
- 只在压力首次跨过6N时触发一次
- 压力保持在6N以上时不能连续重复触发
- 压力下降到5.8N以下后，才允许再次触发
- 建议增加150ms触发冷却时间

### 2. 振幅编辑接口

用户界面使用电压单位编辑，范围：

```
最小振幅：1.8Vpp
最大振幅：3.3Vpp
建议步长：0.05Vpp
```

模块内部继续使用AMP数值：

```
AMP范围：25～47
实际输出约：1.83～3.26Vpp
```

换算公式：

```
Vpp ≈ 0.0651 × AMP + 0.2038

AMP ≈ round((Vpp - 0.2038) ÷ 0.0651)
```

由于模块档位是整数，网页输入1.8～3.3Vpp后，应换算并限制到AMP 25～47。

## 四、瑞芬IMU地址修改

### **1. 梳理设备通信协议及地址修改流程**

结合现有 IMU761 工程和新版 HI91 固件适配代码，明确了设备地址读取、修改及结果确认的基本流程。

串口通信参数采用 115200 波特率、8 位数据位、无校验、1 位停止位。配置时通过 USB-TTL 与单只 IMU 连接，TX 接模块 RXD1，RX 接模块 TXD1，GND 共地。

地址修改采用二进制指令，格式如下：

```
68 05 当前地址 0F 新地址 校验和
```

其中，`68` 为帧头，`05` 为长度字段，`0F` 为地址修改命令，校验和为长度、当前地址、命令和新地址各字段之和的低 8 位。

例如，将地址从 `0x00` 修改为 `0x01`，发送：

```
68 05 00 0F 01 15
```

同时明确，配置指令使用累加校验，HI91 数据帧使用 CRC-16 校验，两种校验方式需要分别处理。

### **2. 开发 Windows 图形化地址配置工具**

完成 IMU761 地址配置工具开发，将原本需要通过串口助手手动拼接和发送指令的操作，整合为图形化配置流程。

工具主要功能包括：

- 选择串口并建立设备连接。
- 接收并解析 HI91 数据帧，通过 CRC 校验检查数据完整性。
- 从新版 HI91 数据帧中读取当前设备地址。
- 输入目标地址，生成并发送地址修改指令。
- 解析地址修改应答，并等待后续 HI91 数据帧返回新地址。
- 对地址输入进行范围检查，支持 `0x00～0xFE`。

程序对串口分段接收、连续数据帧和异常数据进行了处理，避免将一次串口读取直接视为完整数据帧。修改结果通过后续数据帧中的地址确认，减少仅凭“指令已发送”判断成功造成的误判。

## 五、工作相关学习

### 触觉传感器入门调研

触觉传感器用于获取物体接触时的信息，例如：

- **接触位置**：哪里碰到了物体。
- **法向力**：垂直于接触面的按压力。
- **剪切力**：沿接触面方向的力。
- **压力分布**：接触区域内，哪些位置受压更大。
- **表面形状和滑移**：通过传感数据与算法判断接触形态、物体是否滑动。

不同传感器的能力不同，不能默认一个传感器可以测量上述全部信息。

**主要技术路线**

| 类型           | 基本原理                   | 主要特点                 | 调研重点                   |
| -------------- | -------------------------- | ------------------------ | -------------------------- |
| 电阻式与压阻式 | 受力后电阻变化             | 常见薄膜方案容易入门     | 非线性、迟滞、长期漂移     |
| 电容式         | 受压变形引起电容变化       | 可用于持续压力和阵列测量 | 读出电路、寄生电容、标定   |
| 压电式         | 材料受力变化产生电荷       | 适合检测敲击等动态接触   | 低频响应和持续载荷测量限制 |
| 磁式           | 弹性体变形引起磁场变化     | 可结合结构与算法估计受力 | 磁场干扰、结构设计、标定   |
| 视触觉式       | 摄像头观察柔性接触层的形变 | 可获取丰富的接触形状信息 | 光学结构、算法、接触层寿命 |

电阻式可以先看 [Interlink FSR 集成指南](https://www.interlinkelectronics.com/downloads/integration-guides/fsr-400-series-integration-guide.pdf)，电容式参考 [PPS 原理介绍](https://pressureprofile.com/pps-insights/capacitive-tactile-sensing-101)，压电式可参考 [TE 压电薄膜传感器](https://www.te.com/en/product-CAT-PFS0004.html)。磁式和视触觉式的代表案例分别是 [ReSkin](https://reskin.dev/) 与 [GelSight Wedge](https://arxiv.org/abs/2106.08851)。

**注意**：普通电容触摸按键主要检测触摸事件，不能直接等同于测量接触压力的电容式触觉传感器。

**关注的指标**

| 指标         | 初学者可以怎样理解                         |
| ------------ | ------------------------------------------ |
| 测量范围     | 能测多小、多大的力或压力                   |
| 灵敏度       | 输入变化一点，输出变化多少                 |
| 精度与重复性 | 测得准不准，同样按压时结果是否一致         |
| 空间分辨率   | 能区分多近的两个接触位置                   |
| 响应时间     | 接触发生后，多快能反映出来                 |
| 迟滞与漂移   | 加压和卸压是否一致，保持载荷时读数是否变化 |
| 集成难度     | 尺寸、接口、供电、读出电路和算法是否合适   |
| 耐久性       | 反复按压、摩擦后能否正常工作               |

比较参数时，要确认测试条件和单位一致。**力通常用 N，压力通常用 Pa 或 kPa**；接触面积不同，二者不能直接比较。灵敏度高也不代表测量更准确。

初学者可以理解为：柔性材料受压后，内部接触状态发生变化，引起可测量的电容变化，经过采集和标定后得到受力信息。这与仅用于判断手指是否触摸的普通电容按键，在结构和测量目标上都有区别。[来源：赛感离电电子皮肤](https://www.sycsense.com/col_48/)

3 产品体系

赛感公开的产品体系比较适合按完整实验链路调研：

| 产品层级 | 公开产品             | 作用                       |
| -------- | -------------------- | -------------------------- |
| 传感器   | 单点压力传感器       | 测量一个区域的受压情况     |
| 传感阵列 | 16、64、256 通道阵列 | 获取多个位置的压力分布     |
| 采集硬件 | SCM 系列等采集器     | 读取传感器并传输数据       |
| 软件     | DataTerminalPro      | 显示热力图、波形并保存数据 |

其 2025 年产品介绍披露了部分阵列的 0–2000 kPa 检测范围，以及 UART、蓝牙、Wi-Fi 等采集方案；具体接口随采集器型号变化。[来源：赛感产品体系介绍](https://www.sycsense.com/col_26/111.html)

4 公开应用与调研重点

赛感在 2025 年公布了与大寰机器人合作的灵巧手电子皮肤方案，介绍了指尖单点传感器和 16 通道阵列的集成。这可以作为产品集成案例，但不能直接据此判断出货规模。[来源：赛感与大寰合作介绍](https://sycsense.com/col_26/97.html)

建议重点确认：

- 普通压力阵列与三维力电子皮肤分别对应哪些型号？
- 阵列贴在曲面上后，是否需要重新标定？
- 多点同时按压时，相邻通道之间是否相互影响？
- 页面所述响应时间是敏感材料响应，还是整套系统的数据延迟？
- 持续按压、反复弯折后，读数是否发生明显漂移？

**学习重点：从单点压力读数，逐步理解二维压力热力图。**

#### 帕西尼感知科技

1 公司定位与技术路线

帕西尼成立于 2021 年，官方资料明确将霍尔式触觉传感作为核心技术，同时布局触觉传感器、灵巧手及机器人系统。[来源：帕西尼公司介绍](https://product-resources.paxini.com/zh/introduce)

霍尔式触觉的基本思路是：接触使柔性结构发生形变，磁场随之变化，再通过磁场测量和标定模型估计受力。

2 代表产品与公开参数

其 PX6AX 系列覆盖指尖、指腹、掌心等形态。当前官网列有 GEN3 和 GEN4 产品。

以 **PX6AX GEN4 系列页面**为例，厂商披露：

| 项目             | 官网数值或表述                     |
| ---------------- | ---------------------------------- |
| 测量输出         | 三维阵列分布力、三维合力、三维力矩 |
| 测量范围         | 法向 0–25 N，切向 ±10 N            |
| 最小识别力       | 0.005 N                            |
| 最大输出频率     | 1000 Hz                            |
| 内部测量采样频率 | 1 MHz                              |
| 重复精度         | ＜0.5%FS                           |

这些是系列页参数，选型时仍要确认具体型号是否全部满足。[来源：PX6AX GEN4 产品页](https://paxini.com/cn/ax/gen4)

3 调研价值与待确认问题

帕西尼适合重点研究指尖接触中的多方向受力，例如抓住物体时的按压力，以及物体试图滑动时的切向受力。

需要注意，**内部 1 MHz 采样不代表机器人能每秒收到一百万帧完整触觉数据**。实际控制要看对外输出频率、总线带宽和算法延迟。

建议确认：

- 电机、磁铁和金属结构附近的测量表现如何？
- 输出的三维分布力与整体合力分别如何标定？
- 更换表面柔性材料后，是否需要重新标定？
- 多个传感器同时运行时，整手输出频率是多少？

**学习重点：区分法向力、切向力、合力与力矩。**

#### 戴盟机器人

1 公司定位与技术路线

戴盟机器人重点布局视触觉传感器，同时提供触觉夹爪、计算平台及数据采集相关产品。[来源：戴盟官网](https://www.dmrobot.com/)

视触觉可以理解为“用摄像头观察接触层的变化”：物体压在柔性表面上，摄像头记录形变，算法再提取接触形状、形变和受力信息。

2 代表产品

- **DM-Tac W2**：通用视触觉传感器。
- **DM-Tac F**：面向指尖空间的视触觉传感器。

W2 产品页介绍了接触形貌、三维形变场、三维分布力和六维集中力等输出，公开采样频率为 120 Hz。[来源：DM-Tac W2](https://www.dmrobot.com/devices/dm-tac-w2.html)

DM-Tac F 页面则列出 180 Hz 采样频率、USB 2.0 接口，并区分了相机分辨率 640 × 480 与感知分辨率 320 × 240。[来源：DM-Tac F](https://www.dmrobot.com/devices/dm-tac-f.html)

**学习重点：理解图像、形变和力估计之间的关系。**

#### 苏州能斯达

1 公司定位与代表产品

苏州能斯达属于汉威科技旗下企业，适合作为柔性薄膜压力传感器方向的调研对象。

汉威官网介绍的 **ZNS-01** 是能斯达的电阻式柔性压力传感器，厚度小于 0.3 mm，受压后输出电阻发生变化，应用方向包括机器人触觉、智能手套和可穿戴设备。[来源：ZNS-01 产品介绍](https://hanwei.cn/safe_detail_23/ZNS-01.html)

2 为什么适合初学者关注

这类产品便于建立最基础的传感链路：

**按压 → 电阻变化 → 电路转换为电压 → ADC 采集 → 标定为受力信息。**

它适合学习接触检测和按压力度变化。但单片电阻式传感器的输出，不应直接理解为完整的三维力或高精度压力分布。

**学习重点：读出电路、标定、迟滞和漂移。**

#### 墨现科技

1 公司定位与产品方向

墨现科技位于东莞，主要提供柔性压力传感器及应用方案，公开应用覆盖消费电子、汽车、机器人和医疗等方向。[来源：墨现官网](https://www.moxiantech.com/)

其产品可以分为两类理解：

- **单点薄膜传感器**：关注一个区域的受压变化。
- **多点触觉模块与电子皮肤**：关注接触位置和压力分布。

其公开单点产品规格书包含压阻膜、电阻变化及负载条件下的重复性数据，可用于学习如何阅读传感器规格书。[来源：墨现单点传感器规格书](https://www.moxiantech.com/uploads/upload/files/20250413/b8bfc2aa9c2f47dff537480bb278bde2.pdf)

2 机器人产品特点

机器人电子皮肤页面介绍了指腹检测、整手覆盖、背部采集电路和模块间总线通信，并列出 96 点触觉模块。

不过，该页面对阵列排布存在“22 × 8 共 96 点”和“12 × 8 共 96 点”两种文字表述，前者数量不一致，因此具体排布应以正式规格书和图纸为准。[来源：墨现机器人电子皮肤](https://www.moxiantech.com/robot-scene/14)

**学习重点：传感器形态、安装方式与采集电路之间的配合。**

**五、几项会直接影响最终选择的细节**

**1. 途见值得先看文档，但要把软件授权和同步机制问清楚。**

其使用手册已经涉及 CSV/NPZ 导出、标定文件，以及通过 NTP 配置时间同步；GUI 使用还涉及 U-KEY 授权。这些信息有助于提前评估集成，但**不能据此认定 SDK 同样受限，也不能把支持 NTP 等同于已证明毫秒级同步**。应让对方明确 SDK 的独立运行条件，以及时间戳到底对应采样、扫描结束还是发送时刻。[官方使用手册](https://doc.tachintech.com/glove/tachin-glove-manual-zh.pdf)

**2. 墨现、尧乐应重点测试“戴在人手上以后”的数据。**

织物方案与你们的穿戴场景接近。建议优先验证：同一人重新戴上手套后，原标定是否还能使用；不同手型是否改变传感点位置；不接触物体、仅弯曲手指时是否产生明显压力信号。它们各自公开的人手产品方向见[墨现展商资料](https://www.worldrobotconference.com/expo/company/828.html)和[尧乐产品发布稿](https://www.cyzone.cn/article/843404.html)，这些测试建议属于针对你们用途的工程判断。

**3. 华威科、福莱、赛感应重点确认交付边界。**

你们可以提出三档报价，让对方分别回答：

- 触觉阵列；
- 触觉阵列＋采集板＋标定；
- 可穿戴触觉组件＋采集板＋SDK＋定制集成。

这样能看清你们还需要承担多少模拟电路、结构封装和算法工作。**第一轮合作更建议争取第三档，再决定量产时是否收回部分设计。**
