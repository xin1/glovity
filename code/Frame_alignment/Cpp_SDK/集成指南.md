# TeleX 手套 SDK (C++) 集成指南

版本 1.0.0 · 面向集成方的完整说明

---

## 1. 这是什么

一个**零外部依赖**的手套数据 SDK：独占一个 Receiver_RX 串口，后台解析左右手
IMU 帧，实时输出 **21 个手部关节的三维坐标**。

- 语言：对外提供 **纯 C 接口** + 一层 header-only 的 C++ 封装
- 依赖：只依赖 libc / libm / libpthread。**不需要** OpenCV、Eigen、Python 或任何运行时
- 平台：Linux x86_64（在 Ubuntu 20.04 构建，可直接用于 20.04 / 22.04 / 24.04）

## 2. 五分钟跑通

```bash
tar xzf telex-glove-1.0.0-linux-x86_64.tar.gz
cd telex-glove-1.0.0-linux-x86_64

# 无需硬件，先用随包的录制流验证集成链路
./share/telex-glove/examples/monitor_hands file://share/telex-glove/sample_capture.bin
```

接入你的 CMake 工程：

```cmake
find_package(TelexGlove 1.0 REQUIRED)
target_link_libraries(my_app PRIVATE TelexGlove::telex_glove)
```

头文件路径、SONAME、rpath 会自动带上。若你不用 CMake：

```bash
gcc my_app.c -I<pkg>/include -L<pkg>/lib -ltelex_glove -o my_app
```

## 3. 最小可用代码

C++（推荐）：

```cpp
#include <telex_glove.hpp>

telex::GloveHub hub("/dev/ttyACM0");
hub.set_calibration(telex::Hand::Left, "imu_calibration_left.npy");
hub.start();

telex::Snapshot s;
while (running) {
    if (hub.try_wait_next(telex::Hand::Left, 0.1, s)) {
        auto tip = s.joints[4];              // 食指尖，单位米
        int  bat = s.battery_percent;
    }
}
```

纯 C：

```c
#include <telex_glove.h>

telex_glove_hub* hub = NULL;
telex_glove_hub_create("/dev/ttyACM0", 0, &hub);
telex_glove_hub_start(hub, 2.0);

telex_glove_snapshot snap;
memset(&snap, 0, sizeof(snap));
snap.struct_size = (uint32_t)sizeof(snap);      /* 必填 */

if (telex_glove_hub_wait_next(hub, TELEX_GLOVE_HAND_LEFT, 0.1, &snap) == TELEX_GLOVE_OK) {
    /* snap.joints[4] 是食指尖 */
}
telex_glove_hub_destroy(hub);
```

> **`struct_size` 必须填。** 库据此做前向兼容检查；不填会返回
> `TELEX_GLOVE_E_INVALID_ARG`。C++ 封装已自动处理。

## 4. 数据约定

### 4.1 关节布局（21 个）

| 下标 | 含义 | 下标 | 含义 |
|------|------|------|------|
| 0 | 腕部（恒为原点） | 11 | 小指-DIP |
| 1-4 | 食指 MCP/PIP/DIP/TIP | 12 | 小指-TIP |
| 5-8 | 中指 MCP/PIP/DIP/TIP | 13-16 | 无名指 MCP/PIP/DIP/TIP |
| 9 | 小指-MCP | 17-20 | 拇指 CMC/MCP/IP/TIP |
| 10 | 小指-PIP | | |

> ⚠️ **小指占 9-12，无名指占 13-16**，不是按解剖顺序排列。
> 运行时可用 `telex_glove_joint_name(i)` 取 UTF-8 中文名核对。

### 4.2 坐标系与单位

- `joints` 单位 **米**，腕部局部系，`joints[0]` 恒为原点
- 指尖方向 **+Y**，手背方向 **+Z**（掌心 -Z）
- 拇指侧：左手 **+X**，右手 **-X**
- `wrist_euler_deg` 单位度，`wrist_gyro_dps` 单位度/秒
- 四元数一律 `(w, x, y, z)`

### 4.3 排序与时序

- `seq` 单调递增，**可作排序键**
- `frame_id` 来自设备，是 uint16，约 327 秒回绕一次，**不要用来排序**
- `timestamp_ns` 是接收时刻的单调时钟，不是设备采样时刻

## 5. 三步校准

强烈建议提供校准文件，否则关节姿态会带 IMU 贴装偏差。

```cpp
hub.set_calibration(telex::Hand::Left,  "imu_calibration_left.npy");
hub.set_calibration(telex::Hand::Right, "imu_calibration_right.npy");
```

- 直接使用 `Remote_USB_ThreeStepCalibration` 产出的 `.npy`，无需转换
- 文件 **mtime 变化后自动重新加载**，不必重启
- **加载失败不会中断数据流**：该手退回未校准模式，接口返回错误码但仍持续出数
- 可用 `snapshot.calibrated` 判断本帧是否真的应用了校准

> ⚠️ **校准文件自带手别。** 若把右手校准文件配给左手，几何会以**文件**为准
> （这与 Python 版行为一致）。接口返回 OK，但 `telex_glove_last_error()`
> 会留下说明。请核对文件与手别的对应关系。

若校准文件因 numpy 版本过新而无法解析，可用随包脚本转换：

```bash
python3 share/telex-glove/tools/npy_to_tgc.py in.npy out.tgc
```
SDK 同样接受 `.tgc`，接口用法不变。

## 6. 线程安全

| 操作 | 约定 |
|------|------|
| `latest` / `wait_next` / `stats` | **多线程并发安全** |
| `create` / `start` / `stop` / `destroy` | 不可并发，需由同一线程或加锁调用 |
| `set_calibration` | 可与取数并发 |
| `last_error` | thread_local，仅供排查，**不要用于控制流** |

Hub 内部起 **一个** 读线程。`destroy` 会自动 `stop`，运行中直接 `destroy` 是安全的。

> ⚠️ **同一串口只能有一个 Hub。** 若你的程序同时跑调试工具占用了
> `/dev/ttyACM0`，双方都会撕帧。

## 7. 错误处理

C 接口全部返回 `telex_glove_status`；C++ 封装在非预期错误时抛 `telex::Error`
（`try_latest` / `try_wait_next` 对"离线"和"超时"这两种正常情况返回 `false`
而不抛异常）。

常见返回值：

| 返回值 | 含义与处理 |
|--------|-----------|
| `E_PORT_OPEN` | 设备不存在 / 无权限 / 被占用。检查 `ls -l /dev/ttyACM0` 与用户组 |
| `E_NO_DATA` | 该手当前离线（0.35 秒内无有效帧）。正常情况，继续轮询即可 |
| `E_TIMEOUT` | `wait_next` 在给定时间内没等到新帧。正常情况 |
| `E_CALIB_IO` / `E_CALIB_FORMAT` | 校准文件问题。**数据流不受影响**，退回未校准 |
| `E_NOT_STARTED` | 忘了调用 `start` |

`telex_glove_last_error()` 给出更具体的英文诊断，仅用于排查。

## 8. 无硬件调试

把端口写成 `file://<路径>` 即可回放一段录制流，接口行为完全一致：

```cpp
telex::GloveHub hub("file://sample_capture.bin");
```

录制真实数据：`cat /dev/ttyACM0 > capture.bin`（Ctrl-C 停止）。

这条路径也是我方回归测试的载体，可用于和我们比对同一份数据的输出。

## 9. 验收清单

1. `find_package(TelexGlove 1.0 REQUIRED)` 成功
2. `examples/` 下的 C99 与 C++ 示例都能用你们的工具链编译
3. `monitor_hands file://sample_capture.bin` 输出关节坐标，`joints[0]` 为原点
4. `ldd lib/libtelex_glove.so.1` 只有 libc / libm / libpthread
5. 接真硬件：双手 `rx_rate_hz` 正常、`battery_percent` 合理、
   平展姿势下所有关节 `|z| < 0.005`
6. 目标机上不需要安装任何额外运行时

## 10. 已知限制

- `ImuData` 的加速度 / 磁力计 / 校准状态字段在当前固件协议中不传输，故未提供
- 未提供校准文件时，输出仅做腕部相对化，姿态会带贴装偏差
- 断线后不自动重连，需由调用方 `destroy` + 重新 `create`
