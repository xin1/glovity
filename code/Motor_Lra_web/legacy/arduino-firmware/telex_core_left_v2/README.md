# TELEX CORE LEFT V2.0 固件

此固件给板载 ESP32-S3 使用，通过 TCA9548A 分别控制 5 颗 AW86234FCR，并兼容当前网页的串口命令。

## 烧录

1. Arduino IDE 安装 `esp32 by Espressif Systems`。
2. 打开 `telex_core_left_v2.ino`，开发板选择 `ESP32S3 Dev Module`。
3. ESP32-C6 可将 `USB CDC On Boot` 设为 `Enabled`；新版固件也会在该选项关闭时显式使用 HWCDC。上传速度可选 `921600`。
4. 用板子的 USB-C 连接电脑，烧录后重新插拔。
5. 打开本项目网页/EXE，点“连接设备”，选择新增的 USB 串口。

ESP32-S3 启动日志中 0–4 路都应显示 `EVENT DRIVER n OK 2340`。ESP32-C6 必须显示 `EVENT I2C ... TCA OK`，且 `EVENT DRIVER 4 OK 2340` 到 `EVENT DRIVER 7 OK 2340` 四行均为 OK。`MISSING` 表示该器件未应答，应先检查供电、跳线、焊接和 I²C。

## 通道映射

ESP32-S3 五通道版本中，网页手指顺序与硬件通道一致：拇指 0、食指 1、中指 2、无名指 3、小指 4。ESP32-C6 八通道测试板的触觉联动固定映射为：食指 CH4、中指 CH5、无名指 CH6、小指 CH7，大拇指不输出振动；四路可同时以不同振幅工作。手动短振、长振等测试仍会同步测试 CH4–CH7。

C6 四路协议为 `FOUR 食指幅度 中指幅度 无名指幅度 小指幅度 频率`。幅度 `0` 会释放对应马达，非零范围为 `25..47`，例如 `FOUR 30 0 36 25 170`。

## 安全说明

固件把旧网页的 AMP 25–47 映射到经过 1.0.7 测试板验证的 AW86234 电平 18–40。持续非零输出只热更新振幅寄存器，不重复 STOP/GO；释放时执行四个半周期制动并在 16 ms 后清除制动状态。第一次通电仍请从 AMP 25 开始，并根据实际 LRA 的额定电压、线圈温升和机械安装逐步标定上限。

旧交付包中的固件是 ESP32-C6/八通道版本，不能直接烧录到本 ESP32-S3/五通道核心板；这里只移植了已验证的 AW86234 固定宽度驱动与制动策略。
