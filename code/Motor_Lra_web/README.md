# LRA 可视化强度控制

这个版本使用 Arduino Uno/Nano 作为桥接控制器：浏览器通过 USB 串口向 Arduino 发送强度，Arduino 通过 UART 配置 JW-BLE-DL500，并使用 IO1 的低电平连续触发功能控制启停。

## LinkerHand L25 实机触觉数据

网页现在可以直接显示左手 L25 的五指触觉数据，包括法向力、切向力、切向力方向、实时曲线和每根手指的 12 × 6 力矩阵。

Windows 上按下面顺序启动：

1. 双击 `linkerhand\ros2\start-driver.bat`，等窗口出现“成功连接”。
2. 双击 `web\start-linkerhand-web.bat`。
3. 浏览器会打开 `http://127.0.0.1:8765/`，页面底部“L25 实机数据”显示绿色“ROS2 数据流正常”后即可按压指尖测试。

不要重复启动驱动；出现 `PCAN Channel has not been initialized` 时，先运行
`linkerhand\ros2\stop-linkerhand.bat`，再重新启动驱动。Web 窗口可以单独关闭，
它不会占用 PCAN。

桥接程序订阅以下 ROS2 主题：

| 主题 | 类型 | 页面用途 |
|---|---|---|
| `/cb_left_hand_force` | `Float32MultiArray` | 五指法向力、切向力、切向方向、接近量，每组各 5 个值 |
| `/cb_left_hand_matrix_touch` | `String`（JSON） | 五指 12 × 6 压力矩阵 |
| `/cb_left_hand_matrix_touch_mass` | `String`（JSON） | 每根手指的矩阵合值 |

下方五指卡片保留 SDK 原始值；上方采样区按下面的实验换算关系显示 N。若以后取得该批传感器的正式标定曲线，可再替换当前线性换算。

当前项目按暂定两点曲线将指尖矩阵峰值换算为压力：10 点约 0.5 N、140 点约 15 N，显示与振动联动均以 15 N 封顶；原始矩阵值不改写。约 140 点的高端锚点来自当前设备约 7 N 处停止增长的反馈观察，尚未通过砝码实测标定。网页启动后，上方 12 × 6 采集区默认显示下方当前选中手指的实机矩阵；点“实机数据”可以切换回鼠标/数位笔模拟。振动联动默认开启，实机峰值会经过灵敏度死区和感知曲线，同时映射到 LRA 的振幅与频率。

## L25 Web 关节控制与软件标定

页面底部提供 25 个 L25 关节位置滑杆，顺序与 SDK 的 `/cb_left_hand_control_cmd` 完全一致，范围 0–255。修改滑杆只改变目标值，点击“发送姿态”后才会发布，避免调节过程中机械手连续突跳。页面内置“张开、握拳、OK”，也可以把当前目标保存为浏览器本地预设。

“读取当前位置”从 `/cb_left_hand_state` 读取机械手真实姿态。“用当前位置标定”会把这组真实位置保存为软件启动基准；当前 L25 SDK 没有硬件零位标定指令，因此该功能不会擦写电机内部参数。驱动也不再在启动时强制发送猜测的 L25 初始姿态。

## 接线

| Arduino Uno/Nano | LRA 模块 | 说明 |
|---|---|---|
| D10 | TX棕色-绿色 | Arduino 软件串口 RX |
| D11 | RX红色-蓝色 | 建议使用 1k/2k 电阻分压，将 5V 降至约 3.3V |
| D6 | IO1紫色 | 连续振动触发，程序以开漏方式使用 |
| GND | GND橙色-紫色 | 必须共地 |
| 外部 5V/1A | VIN黑色-黄色 | 不建议由 Arduino 3.3V 引脚供电 |

马达只能接 `LRA+` 与 `LRA-`，不能接地。

注意：分压只接在 `Arduino D11 -> LRA RX` 方向。`LRA TX -> Arduino D10`
应直接连接，不要再分压；否则 3.3V 信号会被继续降低，容易出现 `M�U_MODE`、
`O�` 等随机乱码。连接线尽量短，并确保两个设备可靠共地。

## 烧录 Arduino

旧版程序已归档到 `legacy/arduino-firmware/lra_visual_control/`。使用 Arduino IDE 打开其中的 `lra_visual_control.ino`，选择 Arduino Uno 或 Nano 后上传。

程序参数：

- Arduino USB 串口：115200 baud
- Arduino 到 LRA：9600 baud
- 实测 F0：170 Hz

## 振动模式

右侧六个按钮用于选择模式。模式不会随压力自动切换，必须先点击按钮，再在左侧压力区域或实机触觉区触发：

- 默认：90—150 Hz 连续反馈；压力跨过 8% 分档后才改变目标，每次最多渐变 4%，按住多久振动多久
- 短振：默认 150 Hz、AMP 38，单次 60 ms；按下后锁定纵向位置，只识别横向移动
- 长振：默认 130 Hz、AMP 25；按住多久振动多久，松开立即停止；按下后只识别横向移动
- 锯齿：固定实测 F0 170 Hz，高度控制峰值振幅；每轮按五级渐强后断开 40 ms，共播放两轮
- 摩擦：最底部固定 50 Hz，最顶部固定 170 Hz；鼠标越往上频率和振幅越大，只由垂直位置决定，与移动速度无关
- 碰撞：只有按下位置对应的模拟压力达到 6 N 才触发；默认 170 Hz、AMP 33、28 ms；按下后只识别横向移动

## 可编辑频率和振幅

网页“输出参数”区域可修改：

- 频率：20—500 Hz
- 最大振幅：AMP 25—47，对应约 1.83—3.26 Vpp

修改后点击“应用到设备”。网页发送 `PARAM 频率 最大振幅`，Arduino 再通过
`SET_FREQ`、`SET_AMP1` 和 `ACTION` 将参数写入 LRA。最大振幅同时作为六种预设
效果的输出上限；锯齿各段振幅会按同一比例缩放。

不同模式会载入不同默认值：短振 150 Hz/AMP 38，长振 130 Hz/AMP 25，
锯齿 170 Hz/峰值 AMP 42，摩擦 50—170 Hz/最大 AMP 35，碰撞 170 Hz/AMP 33。
摩擦的频率端点和锯齿的 170 Hz 频率固定，两者的最大振幅仍可编辑。
短振、长振和碰撞使用当前固定的频率与振幅；摩擦和锯齿通过垂直位置调节振幅。
摩擦频率按垂直位置线性映射：最底部 50 Hz、最顶部 170 Hz；频率只由当前位置决定，与变化速度无关。

六种效果使用非阻塞状态机，通过 `D6 -> LRA IO1` 产生和停止振动。模块串口协议
没有单独的停止指令，因此要让“立即停止”真正中断正在播放的效果，必须连接 IO1。

为降低触发延迟，网页会在选择模式时提前发送 `PREP`，先把该模式的频率和振幅
写入模块。真正按下控制区时，如果参数没有变化，Arduino 会直接触发 IO1，不再
重复配置。Arduino 在等待模块回复期间会保留最新控制命令，并把连续产生的
`HOLD` 合并成最新一条，避免串口积压后仍执行过时的鼠标位置。

## 压力阈值

普通鼠标没有真实压力数据，网页暂时把线条高度映射成 `0—10 N`。左侧只显示
压力数值，不再用压力区间自动选择振动类型；振动类型由右侧按钮选择。碰撞是
唯一带硬阈值的模式，必须在 6 N 或更高的位置按下才能触发。短振、长振和碰撞
在按下瞬间记录这个位置，之后锁定纵向输入，因此移动轨迹保持为横线。

## 检测马达 F0

连接设备并等待初始化完成后，点击网页“输出参数”区域的“检测 F0”。检测前应把
马达可靠固定在最终安装位置，检测过程中不要触碰马达。网页会发送 `DETECT_F0`，
Arduino 再向驱动模块发送 `F0_DET`。成功时串口日志和界面会显示类似：

```text
F0_DET,OK!
LRA_F0:170Hz
EVENT F0 170
```

其中 `170 Hz` 就是检测到的谐振频率。驱动模块会自动把当前输出频率调整到检测值；
开始下一种网页振动效果时，程序会再写入该效果需要的频率。

## `MCU_MODE` 无回复时

网页能显示 `LRA controller started`，说明电脑到 Arduino 的 USB 串口已经正常；
`Timeout waiting for LRA response` 表示问题位于 Arduino 和 LRA 模块之间。

请严格按下面接线（不要接 Arduino 的 D0/RX、D1/TX）：

```text
LRA TX  -> Arduino D10 绿色
LRA RX  <- Arduino D11 蓝色
LRA GND -> Arduino GND 紫色
LRA VIN -> 3.0-5.0 V 稳定电源 黄色
```

上传程序或打开网页串口前，先关闭占用同一个 COM 口的 Arduino 串口监视器。
如果接了 `D6 -> IO1`，排查串口时可以先断开这根线；它不影响参数配置。
发送 `MCU_MODE` 时观察模块指示灯：红灯闪烁表示模块已经收到指令，此时重点检查
`LRA TX -> D10`；完全不闪则重点检查 `D11 -> LRA RX`、模块供电和共地。

如果日志出现 `EVENT WARN RECOVERED_DAMAGED_OK`，表示程序从一次损坏的 `OK!`
回复中恢复并继续运行。偶发一次可以继续使用；如果频繁出现，说明 D10 接收方向
仍有信号质量问题，应检查是否误加分压、杜邦线过长或 GND 接触不良。
- 可调振幅：AMP 25—47，约 1.83—3.26 Vpp
- 网页心跳丢失 800 ms 后自动释放 IO1

## 启动网页

Web Serial 需要 Chrome/Edge，并应从 localhost 打开。进入 `web` 目录后运行：

```powershell
python -m http.server 8000
```

然后用 Chrome 或 Edge 打开：

```text
http://localhost:8000
```

点击“连接设备”，选择对应的 COM 口。打开串口时 Arduino 会自动复位；等待界面显示“设备就绪”后，先在右侧选择振动模式，再在左侧区域操作。

不要同时打开 Arduino IDE 串口监视器和网页，它们不能同时占用同一个 COM 口。

## 浏览器发送协议

```text
FRICTION_START FORCE_X10 MIN_FREQ MAX_FREQ MAX_AMP  按当前位置开始摩擦
FRICTION_HOLD FORCE_X10 MIN_FREQ MAX_FREQ MAX_AMP   更新位置并保持摩擦心跳
START AMP FREQ       兼容旧版的连续振动命令
HOLD AMP FREQ        兼容旧版的连续更新命令
PULSE FREQ AMP MS    播放自定义短振
LONG_START FREQ AMP  开始长振，按住期间由心跳维持
LONG_HOLD FREQ AMP   更新长振并延长持续时间
LONG_RELEASE         松开长振并立即停止
SAW_PLAY FREQ AMP    播放固定 170 Hz 锯齿，AMP 为峰值；五级渐强、40 ms 断开，共两轮（FREQ 保留用于兼容）
COLLISION FORCE_X10 FREQ AMP  压力达到 60（即 6.0 N）才播放碰撞短振
STOP                 立即释放 IO1
PARAM FREQ AMP        设置当前模式的基准频率和最大振幅
PREP FREQ AMP         预加载所选模式参数，不触发振动
DETECT_F0             检测马达谐振频率并返回 EVENT F0 频率
CONFIG               重新配置 LRA
```

`FRICTION_START/FRICTION_HOLD` 直接携带当前模拟力度，Arduino 根据力度计算频率和振幅，再转换为 LRA 的 `SET_FREQ`、`SET_AMP1`、数值和 `ACTION` 指令。这样摩擦频率的来源始终是力度，而不是鼠标移动速度或前端缓存的旧频率。

## 12 × 6 触觉压力模拟与振动映射

采集面板固定为与 L25 指尖一致的 12 行 × 6 列，无需连接串口即可预览。按住鼠标左键拖动，
圆圈表示采集点，覆盖范围内各点的箭头始终指向鼠标按压中心；不显示方格和压力数值。
鼠标所在采集格及周围一圈形成 3 × 3 覆盖区域，面板边缘自动裁切。每根箭头的长度、亮度和线宽由对应点的局部压力决定。

设定压力初始为 4 N，键盘 `+` / `-` 或面板加减按钮每次调整 1 N，限制在
0–15 N。设定值表示中心峰值；热力图显示按距离衰减后的局部压力，并非总力分摊。
热力图单独显示在采集模块下方的方形面板中，使用固定的 0–15 N 色标：0 N 蓝色、4 N 黄色、15 N 红色。
桌面布局为左侧波形、中间采集点与热力图、最右侧设备连接、振动模式和串口日志。
左侧压力波形随按压压力变化，松开、取消指针、切换窗口或立即停止后回到零。
输入设备参数时不会拦截加减键。连接 LRA 后，采集压力会经过 0.4 N 抗噪死区和分段感知曲线映射到振动强度：5 N 以下采用平方曲线压低轻触输出，5 N 以上平滑增加，15 N 达到当前设置的最大 AMP。整体振幅范围为 0–75，振幅从设定上限约 5% 起步，以拉大轻按与重按的差别；界面会实时显示计算后的 AMP 和百分比。

L25 运动控制默认开启平滑轨迹。后端以 25 Hz 使用五次最小冲击曲线插值，网页可选择慢（50）、正常（90）、快（150）三档速度，设置 0.5–3.0 秒平滑时间和 0–255 最大力矩；“立即停止”会取消轨迹并保持最新回读位置。

交互逻辑检查：`node web/tests/tactile.cjs`。

采集区间距缩紧，下方总方向按覆盖内采集点的局部压力对指向中心的向量加权合成；
对称按压显示“方向平衡”，零压力与松开时隐藏箭头。方向点覆盖仍为 3 × 3，
热力图独立显示完整高斯扩散，不裁切到接触范围，低压外围渐隐至深色背景。
左侧保留原有波形高度，不随其他列拉伸；中间采集区最大宽 270 px，彩色图最大边长 240 px。
中间与右侧随行高对齐，窄屏仍按响应式布局排列。

界面顶部显示“触觉采集 · 12×6”，主标题为“采样率”；总方向标签为“合力”，颜色图标题为“压力”。
热力图使用 13 个颜色节点连续插值，从蓝、青、绿、黄自然过渡到橙、红，保留 4 N 黄色和深色低压外围。

## 数位笔压感输入

在采集圆圈区域用数位笔落笔，页面根据 Pointer Events 的 `pointerType=pen`
读取 `pressure`，将 0–1 线性映射为 0–15 N 模拟力，并同步波形与热力图。
覆盖仍保持 3×3；抬笔、取消、丢失指针捕获或窗口失焦后归零。
采集区上方显示输入类型及原始笔压百分比，便于实机确认数据是否随力度变化。
鼠标和触屏仍使用加减键/按钮调节，切回时恢复上次手动设定值。
笔按压期间不允许加减键覆盖笔压。无有效笔压时显示“未提供”，输出模拟力为零。
连接马达且设备就绪后，数位笔会输出摩擦振动；未连接时仅预览。显示的牛顿数为模拟值。


### 数位笔联动摩擦模式

初始选择“默认”平滑连续模式；落笔保留右侧选中的模式。选摩擦时沿用 50–170 Hz 和当前摩擦最大振幅（默认 AMP 35）。
笔压 0–1 / 显示 0–15 N 被归一化为固件 `FRICTION_START/HOLD` 的 0–100 输入，
因此不需要重新烧录固件，15 N 才达到完整输出范围。原左侧控制区保留原有映射。
非零笔压开始振动，移动或原地改变笔压更新输出，复用 90 ms 节流和 300 ms 心跳。
零压、抬笔、失焦、取消或立即停止会发送 STOP；零压后再加压可继续摩擦。
落笔时设备未就绪则仅预览，连接就绪后需重新落笔才能输出，避免中途意外开始。


### 采集区输出诊断

采集区显示马达未连接、初始化中、零压力、已发送启动请求或设备已确认启动。
串口日志新增 INPUT 输入来源及 TX 启停命令，便于核对事件是否到达串口。
笔、鼠标和触屏均可启动摩擦输出；鼠标/触屏使用手动模拟压力。
快速重新按压时，前一次 STOP 的延迟回执不会清除新按压的心跳；
非预期的设备停止仍会结束当前按压，防止自动重启。


### 点按与起始压力

第一次输出即使用落笔压力：0–1 笔压映射为 50–170 Hz、AMP 25–当前最大振幅，
零压力不启动。取消固定强度的起振段和 90 ms 延迟跟随。
只有已确认的马达参数与本次压力完全匹配时才直接 START；不匹配时立即发送
对应压力的 FRICTION_START，不借用上次强按的振幅。频率与振幅切换仍需设备配置时间。
保留参数缓存、松开立即 STOP 和未发送旧命令清理，无需重新烧录固件。

### 采样区的六种模式

右侧选择后，数位笔、鼠标和触屏均沿用当前模式，不会在落笔时切回摩擦。
短振每次接触触发一次 60 ms，振幅按触发时的压力在 AMP 25 与所设上限间映射；
默认上限 38 时，20% 笔压为 AMP 28，80% 笔压为 AMP 35。零压力不触发。
持续按住或收到播放完成回执不会重复播放，松开再按可触发下一次。
默认模式使用 START/HOLD/STOP，长振使用 LONG_START/HOLD/RELEASE，两者都在松开时立即停止；锯齿按压力决定峰值并播放两轮；
碰撞在达到 6 N 时触发一次 28 ms。短振、锯齿和碰撞正常松开后完成当前有限效果，
取消、失焦、切换模式或“停止输出”立即 STOP。摩擦正常松开仍立即停止。
所有命令复用现有固件协议，无需重新烧录。
