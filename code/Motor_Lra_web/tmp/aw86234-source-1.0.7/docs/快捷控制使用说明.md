# 快捷控制

所有日常操作都在「快捷控制」页完成，不再单独设置“实时调试”标签。

## CONT：持续实时控制

选择 CONT，默认显示“持续实时控制 · 直到停止”。选择通道和触感预设，点击“开始持续振动”。运行时调整强度、强弱变化、变化速度和深度，或直接切换预设，无需再次下发。

勾选“自动谐振跟踪”时频率不可手动编辑；取消勾选后可以调整手动频率。切换两种驱动方式会短暂停振。点击停止或按 Esc 结束。控制连接失联会自动停机。切换到 RAM/TRIG 或定时播放时，会请求停止正在运行的持续实时控制。

CONT 下拉框也可选“定时播放 · 到时停止”，保留原来的时长设置和参数导入、保存功能。

## RAM / TRIG：选择预设后播放

1. 选择 RAM 或 TRIG，以及目标通道。
2. 在“触感预设”中选择要试听的效果，或选择“使用已有波形（自定义）”并填写已有波形号、采样率。
3. 点击“▶ 播放一次”，自动写入参数并播放，无需先点击写入。

RAM 的“最长播放”是停止上限；波形播放完会提前结束。TRIG 的“写入并启用 BOOT”只部署、不立即播放，之后按板上 BOOT 每次触发一次；界面的播放按钮可直接试听。

若设备已有不同的波形库，默认不会覆盖。需要写入新预设时，勾选“允许预设替换设备波形库（原波形自动备份到本机）”。替换前先备份到 `%LOCALAPPDATA%/AW86234/waveform-backups`。写入预设会把所选通道的库替换为一个预设波形，不是追加。备份失败时不写入设备。设备波形断电后需要重新写入。

预设用于试听比较，实际触感仍取决于马达、安装和佩戴情况。
