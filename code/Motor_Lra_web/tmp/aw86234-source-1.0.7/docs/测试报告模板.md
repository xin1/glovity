## 5. 安全机制验证（验收标准第 10 条）

| 场景 | 操作 | 期望 | 实测 | 判定 |
|---|---|---|---|---|
| 拔掉 USB | 播放中直接拔线 | 固件在 `play_timeout_ms` 内停止全部通道；复插后 `GET_STATUS.safety_state = 1` | | ☐ |
| 请求 8 路满幅 | `PLAY_MULTI(mask=0xFF)` 且未带 override | 返回 `ERR_SAFETY_LIMIT`，`started_mask` 不包含超限通道 | | ☐ |
| 关闭上位机进程 | 播放中杀进程 | 固件在 `heartbeat_timeout_ms` 内停机、`TRIG_PARK`、进安全态 | | ☐ |
| 触发后停不下来 | TRIG 播放中发 `STOP(immediate=1)` | 立即停止；`0x3A bit2` 回读为 1 | | ☐ |
| `SET_TRIG_PARAMS(trig1_stop=0)` | 故意关闭 | 被拒（`ERR_BAD_PARAM`） | | ☐ |
| 上电静默 | 上电后立即示波器看 TP9 | 无任何误触发（V-3 风险窗口已尽量缩短） | | ☐ |
