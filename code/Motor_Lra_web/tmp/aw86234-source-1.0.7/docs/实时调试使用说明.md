# 实时调试（固件 1.0.3）

打开上位机的「快捷控制 → CONT → 持续实时控制」模块，选择在线通道，点击「开始持续振动」。本模式没有正常播放倒计时，直到「全部停止」/ Esc、退出上位机或设备保护触发才结束。传统快捷控制页的定时播放保持不变。

## 自动谐振与手动频率

- 默认勾选「自动谐振跟踪」。固件使用 CONT 跟踪模式，手动频率框禁用；初始谐振参考为 168 Hz，实际频率由芯片跟踪，不把这个数字当作测得频率。
- 取消勾选后，固件使用 Auto Dynamic Sine，可在 60–300 Hz 范围内以 0.1 Hz 设置频率。输入值是请求频率，不是机械频率测量；芯片系数量化及马达响应会影响输出。
- 播放中切换勾选项需要短暂停振后切换驱动方式。同一方式中调节参数不重复 GO。
- 选择预设保留跟踪勾选状态与之前的手动频率。

## 播放中调整

强度范围 0–77，是驱动电平而非物理振幅。可以调整强弱变化形状、变化速度（0.1–30 次/秒）和深度（0–100%）。深度为 0 时没有强弱起伏，为 100% 时包络允许降到零；降低强度到 0 仍是运行中的会话，恢复强度无需再次启动。

预设：平稳持续、轻柔呼吸、节奏脉冲、双击节奏、衰减敲击、颗粒纹理。它们是可比较的候选触感，并不保证对应的主观评价。双击与敲击是周期重复的包络，频率框表示载波频率，变化速度表示重复节奏，两者不同。

自动跟踪模式由固件安全任务周期性更新幅度；手动频率模式由固件生成动态正弦参数并维护 FIFO。变化响应受芯片缓存、I2C 和调度影响，不声称任意调制速度都能由马达忠实还原。对于清脆单次点击，仍可使用 RAM/TRIG 的上传波形。

运行中控制对象固定为启动时通道。修改顶部勾选不会把当前会话转移到其他马达；新选择在停止后下一次开始时生效。离开实时页仍继续播放，可从任何页面点击顶部停止或按 Esc。

## 停止与保护

上位机每 400 ms 发送专用续约。若连续 2 秒失去实时控制续约，固件停止整组通道；普通心跳不能代替实时续约。这样正常工作可以不限时，而上位机卡住、退出或控制任务停止后不会无限振动。

STOP、通道重新配置、其他播放接管、总线故障或设备故障会撤销会话；恢复连接不会自动重新启动。错误提示中的「实时控制失联」表示专用控制续约中断，与正常定时播放结束不同。

## 协议

能力位 `CAP_LIVE_LAB = 1 << 18`。

`LIVE_CONTROL (0x4D)` 请求 10 字节：action（0=start、1=update）、通道 mask、frequency_x10（u16LE）、amplitude、envelope、rate_x10（u16LE）、depth、tracking。成功应答逐字节返回请求。tracking=1 要求 frequency_x10=1680；tracking=0 支持 600–3000。幅度 0–77，包络 0–4，速度 1–300，深度 0–100。UPDATE 不能恢复已结束或过期的会话。

`LIVE_KEEPALIVE (0x4E)` 请求/应答均为 1 字节会话 mask；仅这个命令续约。已有 STOP/STOP_ALL 无变化。`TRIP_LIVE_LEASE=4` 表示实时会话失联。

实时会话不写入 SRAM 波形库。启动会配置所选通道的运行参数；之后回到 RAM/TRIG 时重新下发对应参数。
