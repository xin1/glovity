# 上位机模块接口约定（内部契约）

> 本文件锁定 `host/awtest/` 各模块之间的**函数签名**，避免并行开发时接口漂移。
> 已有实现（**不要修改其签名**）：`protocol/framing.py`、`protocol/commands.py`、
> `protocol/codec.py`、`protocol/transport.py`、`device.py`、`profiles.py`。

```python
# awtest/script/schema.py
OPS: frozenset[str]
@dataclass class Step:
    op: str
    params: dict
    index: int = 0
    raw: dict = field(default_factory=dict)
@dataclass class TestScript:
    name: str = ""; matrix_ids: list[str] = []; description: str = ""
    channels: list[int] = []; steps: list[Step] = []; path: str | None = None
    metadata: dict = {}
def parse_script(data: dict, path: str | None = None) -> TestScript   # 非法时抛 ValueError

def save_script(script: TestScript, path: str) -> None
def list_preset_scripts(directory: str | None = None) -> list[tuple[str, str]]
    # [(显示名, 路径)]，默认查 awtest/resources/scripts/

# awtest/script/engine.py
@dataclass class StepResult:
    index: int; op: str; chan: int | None; params: dict
    expected: str = ""; actual: str = ""; status: str = "skip"   # pass/fail/skip
    elapsed_ms: float = 0.0; note: str = ""; matrix_id: str = ""

    script: TestScript; started_at: str; finished_at: str = ""
```

## 5. 补充（实现时补充说明，不改动第 2、3 节的签名）

1. **参数换算模块位置**：`F_PRE ↔ F0`、`F0 = 192000/(H*256+L)`（一次性检测；**实测修正**，
   手册写的 384000 对该寄存器差 2 倍，跟踪寄存器 `0x26/0x27` 仍用 384000）、`DRV_LVL → VDD*L/128`、
   `DSP 时间 code/48000 ↔ µs`、`VDD = 6.1*AVG/1023`、`RL = 610*AVG/(1023*D2S_GAIN)`
   等换算函数放在 **`awtest/waveform/convert.py`**（与接口约定第 2 节同包，界面与脚本都可直接
   `from awtest.waveform import convert` 调用），未新增 `awtest/convert.py`。
2. **`sram_budget()` 的"可用字节"口径**：返回 ``(used, avail, overflow)``，
   ``used = 1 + 4N + Σlen``；``avail`` 直接取 ``base_addr``（本板默认 `0x0800`，
   即波形库可用 **2048 字节**，上限不超过 SRAM 总容量 3 kB）。
   固件 `WAVE_BEGIN` 应答里的 `max_total_samples` 才是权威上限，本函数只用于界面**提前拦截**。
3. **`Step.params` 的口径**：等于该步 JSON 里**除 `op` 以外的全部字段**（含可选的嵌套
   `params` 对象），`Step.raw` 保留原始字典。`set_profile` 的 Profile 字段两种写法都支持：
   嵌套 `{"params": {...}}` 或直接写在步上；`Step.profile_fields()` 会合并两者。
4. **断言步的被测值来源**：`assert_equals` / `assert_range` 支持
   `actual` / `value`（字面量、`"$人工字段名"`、`{"manual": "字段"}`）、
   `field` / `manual`（取自 `run.manual`）、以及 `previous: true`（上一步的实测值）。
   `assert_read` 的 `expect` 字符串按**十六进制**解析（可写 `0x1C` 或 `1C`），
   并支持 `mask` 与 `tolerance`。
5. **`expect_error` 的取值**：`true`（任意错误应答都算通过）、错误码数字、`"0x10"`、
   `ERR_xxx` 名字，或它们的数组；命中即 `pass`，否则 `fail`。断言步把 `expect` 直接写成
   `ERR_xxx` 时按同样规则比对。
6. **引擎额外支持的 op**（第 3 节的必需集合之外）：`ping`、`get_caps`、`get_status`、
   `get_safety`、`set_safety`、`clear_errors`、`bus_*`、`tca_*`、`ch_probe`、
   `ch_probe_all`、`ch_get_info`、`aw_*`、`set_default_profile`、`set_gain`、`set_vbat`、
   `set_cont_live`、`set_*_params`、`rtp_data`、`wave_begin`、`wave_abort`、`wave_queue`、
   `wave_readback`、`wave_get_library`、`play_multi`、`get_play_state`、`sweep_abort`、
   `mon_start` / `mon_stop`、`test_run` / `test_abort`、`selftest`、
   **`wait_play_done`**（等 `EVT_PLAY_DONE`，可断言 `expect_reason`）与
   **`wait_event`**（等任意事件帧，可断言 `reason`）。
   `ScriptEngine.__init__` 额外接受可选参数 `event_timeout_ms`（事件等待默认超时，毫秒）。
