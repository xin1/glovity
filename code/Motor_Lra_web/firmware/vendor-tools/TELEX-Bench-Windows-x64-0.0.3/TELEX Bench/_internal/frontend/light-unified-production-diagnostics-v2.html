磁力计校准

默认经接收器无线校准；有线 USB 为主动选择的备选方案。

校准任务设置

先让手套预热约 5 分钟，再缓慢向各方向旋转。开始后查看实际收到的 IMU 数据。

  • 无线模式通过接收器发送 START/STOP/ABORT，并持续跟踪目标数据。
  • 有线模式开始前自动检查目标手套 USB 是否存在。
  • 断连会结束本机会话；无线取消使用 ABORT，有线退出由固件决定。保存以 COMPLETE 为准。
