AW86234 触觉反馈交付包 1.0.7
打包日期：2026-10-01；Windows x64；测试板：ESP32-C6 / AW86234。

一、直接使用
完整解压ZIP，双击 Start.cmd 或 app/AW86234-Haptic-Control.exe。
不需要安装Python。顶部选择振动板COM32并连接，进入“触觉反馈”。
本机已验证：PX-6AX传感器COM7、地址3；马达CH4；最大电平40。
换电脑时COM口编号可能改变，请按设备管理器显示填写。
四种触感：连续压力、力度顿挫、柔和呼吸、双击节奏。
停止按钮或Esc停止；图表为自动滚动双轴，禁用鼠标缩放/拖动。
输出曲线表示下发电平，不是实测机械振幅。

二、固件
本机当前已烧录并验证1.0.7，不需要为了使用本包再次烧录。
已有测试板升级：先关闭上位机/串口监视器，双击 Flash-Update.cmd。
输入振动板COM口，直接回车使用COM32。只更新0x10000应用区。
新板初始化：双击 Flash-New-Board.cmd，写入引导、分区表及应用。
这是ESP32-C6测试板固件，不能用于ESP32-S3核心板或其他板型。
烧录入口调用随包附带的便携工具，自动校验待写文件SHA256。
不执行全片擦除。分区布局与本项目一致。

固件地址：
0x00000 firmware/bootloader.bin
0x08000 firmware/partition-table.bin
0x10000 firmware/app-1.0.7.bin

三、版本内容
沿用用户已确认的连续稳定驱动、清脆短击/双击、合并锁定图表。
1.0.7修复短击结束后制动未退出导致的酥麻残振；用户已确认消除。
主机150ms数据新鲜度、固件300ms触觉租约和故障停机保护保留。

四、文件与排查
docs：完整实现/验收记录及本机示例配置。
source：本次对应源码快照；开发构建仍需Python依赖与ESP-IDF 6.0。
tools：便携esptool烧录器；licenses：第三方许可信息及来源。
SHA256SUMS.json：交付文件校验值；RELEASE.json：版本与验证记录。
上位机启动诊断日志：%LOCALAPPDATA%/AW86234/logs/startup.log。
本包未做Windows代码签名。
