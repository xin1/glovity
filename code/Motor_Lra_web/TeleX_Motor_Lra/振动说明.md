# 振动说明

## 1. 同步文件

本文涉及界面输出参数时，以 `code` 目录中的最终运行代码为唯一依据；根目录同名功能文件仅为早期同步参考，不参与 `code/index.html` 的运行。

| 文件 | 用途 |
|---|---|
| `code/linkerhand_bridge.py` | 最终网页服务、ROS 2 数据桥和 SSE 接口 |
| `code/app.js` | 最终压力映射、模式选择、频率与振幅控制逻辑 |
| `code/telex-device.js` | 最终 TELEX v1 USB 协议、AMP 映射和五路输出实现 |
| `code/index.html` | 最终界面入口，只加载上述 `app.js` 和 `telex-device.js` |

根目录的 `tactile_only_bridge.py` 和 `tactile-haptics.js` 不作为本文振动参数的最终判定依据。

## 2. 压力计算

优先使用桥接数据中的：

```text
matrix_stats[finger].peak_n
```

若没有 `peak_n`，取该指矩阵最大原始点，再使用当前暂定换算：

```text
N = min(15, raw / 20 + 8 × raw × (raw - 10) / 18200)
```

当前标定锚点：

- 原始峰值约 10 点，对应约 0.5 N；
- 原始峰值约 140 点，对应约 15 N；
- 超过 15 N 封顶。

这是暂定两点标定，不是传感器的最终计量标定。正式产品应使用砝码逐指标定，并允许每根手指保存独立曲线。

## 3. 压力到振幅

### 3.1 压力归一化

设启振阈值为 `T`。最终 `code/app.js` 默认使用第 5 档“高灵敏”，对应 `T=0.05 N`；其余档位依次为 `2.0、1.6、1.2、0.8、0.05 N`。

```text
P <= T:             level = 0
T < P < 5 N:        level = 0.25 × ((P-T)/(5-T))²
5 N <= P <= 15 N:   level = 0.25 + 0.75 × (P-5)/10
```

低压力段使用平方曲线，避免接触噪声导致突兀强振；5–15 N 使用线性上升。

### 3.2 UI AMP

当前 UI 的全局振幅上限默认是 `AMP 47`：

```text
uiAmp = round(maxAmp × (0.05 + 0.95 × level))
```

只有压力越过当前灵敏度阈值后才计算并输出 AMP；未越过阈值时，最终发送电平为 0。

### 3.3 UI AMP 到固件电平

固件接受范围是整数 `0..40`。映射规则：

```text
AMP 0       → 0
AMP 25      → 18
AMP 26..47  → 19..40
AMP >= 47   → 40
```

因此 `AMP 47` 是固件满幅 `40/40`。不要再乘 `40/75`，否则 `AMP 47` 只会得到约 25，振感明显偏小。

### 3.4 多指能量预算

固件与上位机都保留总能量限制：

```text
sum(level[i]²) <= 7200
```

超出时，五路等比例缩放：

```text
factor = sqrt(7200 / sum(level[i]²))
level[i] = floor(level[i] × factor)
```

单指可达到 40。五指同时请求 40 时会被限制到约 37/路，这是安全策略，不是强度映射错误。

## 4. 频率

### 4.1 连续触觉反馈

最终 `code/app.js` 对 `telex-v1` 的处理为固定 `168 Hz`：

- `frequencyForPressure()` 在设备为 `telex-v1` 时只返回 `168` 或 `0`；
- `code/telex-device.js` 的实时输出包 `0x21` 只携带五路马达电平；
- 压力变化实时改变振幅，不会改变连续振动频率；
- 连接 TELEX v1 后，网页禁用频率输入和 F0 检测按钮。

旧版非 TELEX v1 串口板仍保留约 `94 Hz` 到界面设定上限的压力映射，但不属于 TELEX v1 最终输出行为。

### 4.2 各模式对应频率、振幅与时长

| 模式 | 频率 | 振幅 | 触发/时长 |
|---|---:|---|---|
| 默认 | 固定 `168 Hz` | 压力映射 AMP，默认最大 `47`，实际电平最大 `40` | 越过灵敏度阈值后持续输出 |
| 短振 | 网页不下发频率，由固件 `preset=0` 决定 | 触发压力映射 AMP，实际电平 `1–40` | 单次 `18 ms` |
| 长振 | 固定 `168 Hz` | 持续按压力映射 AMP | 按住多久振多久 |
| 摩擦 | 固定 `168 Hz` | 持续按压力映射 AMP | 按压/摩擦期间持续输出 |
| 碰撞 | 网页不下发频率，由固件 `preset=3` 决定 | 碰撞压力映射 AMP，实际电平 `1–40` | 输出门槛 `>=6 N`，单次 `60 ms` |

`code/telex-device.js` 将有限振动时长限制在 `1–200 ms`，并把 AMP 映射到 `1–40` 的固件强度。当前网页实际为短振请求 `18 ms`，为碰撞请求 `60 ms`。

仅根据 `code` 目录无法确定短振和碰撞预设波形的具体频率；该值由设备固件内部波形定义决定，文档不再把它写成可由网页确认的 `166.67 Hz`。

## 5. 输出模式

### 5.1 五指模式

每帧分别计算五根手指：

```javascript
const frame = TeleXStudioTactile.mapTactileState(state, {
  mode: "five",
  thresholdN: 0.5,
  maxAmp: 47,
});

// frame.levels 顺序固定：little, ring, middle, index, thumb
await telexDevice.update(frame.levels);
```

### 5.2 单指模式

单指模式仍使用同一份五指映射，只将未选择的四路置零：

```javascript
const frame = TeleXStudioTactile.mapTactileState(state, {
  mode: "single",
  selectedFinger: "middle",
  thresholdN: 0.5,
  maxAmp: 47,
});
```

选择关系必须是：拇指→CH4、食指→CH3、中指→CH2、无名指→CH1、小指→CH0。

## 6. 触觉数据来源

### 6.1 ROS 2 主题

左手机械手默认读取：

| 主题                              | 类型                             | 用途                                           |
| --------------------------------- | -------------------------------- | ---------------------------------------------- |
| `/cb_left_hand_matrix_touch`      | `std_msgs/msg/String`            | 五指压力矩阵 JSON，主要数据源                  |
| `/cb_left_hand_matrix_touch_mass` | `std_msgs/msg/String`            | 每指矩阵合值，可用于显示或诊断                 |
| `/cb_left_hand_force`             | `std_msgs/msg/Float32MultiArray` | normal/tangential/direction/approach，每组五指 |

不要订阅 `/cb_left_hand_state`，也不要发布 `/cb_left_hand_control_cmd` 或 `/cb_hand_setting_cmd`。

### 6.2 只读 HTTP/SSE 桥

启动：

```powershell
python .\telex-studio-sync\tactile_only_bridge.py --hand left --port 8766
```

接口：

```text
GET http://127.0.0.1:8766/api/tactile/state
GET http://127.0.0.1:8766/api/tactile/events
```

`events` 是 Server-Sent Events，事件名固定为 `tactile`。建议 TeleX Studio 使用 SSE，避免高频轮询。

主要数据结构：

```json
{
  "sequence": 120,
  "connected": true,
  "updated_at": 1793070000.125,
  "matrices": {
    "thumb": [[0, 1]],
    "index": [[0, 12]],
    "middle": [],
    "ring": [],
    "little": []
  },
  "matrix_stats": {
    "index": {
      "sum": 36.0,
      "max": 12.0,
      "peak_n": 0.61,
      "contacts": 3,
      "valid": true
    }
  }
}
```

`connected=false` 表示超过 2 秒没有收到任何触觉更新。此时必须立即向振动设备发送全零或 STOP。

## 7. TELEX 振动协议要点

已验证的浏览器参考实现是 `web/telex-device.js`。TeleX Studio 若自行实现传输，需要保留：

- TELEX v1 数据包、CRC16-CCITT 和 USB COBS 封装；
- 身份查询 `0x01`；
- 能力查询 `0x02`；
- 时钟同步 `0x40`；
- 会话开始 `0x20`；
- 五路实时电平 `0x21`，负载恰好 5 字节；
- 急停 `0x22`，空负载；
- 有限短振 `0x23`；
- ACK `0x7e`。

通过 C6 接收器连接时：

- C6 USB 身份是 `role=3`；
- 左手目标是 `role=1`；
- C6 会将目标为左手的包经 ESP-NOW 转发；
- C6 自己周期发送的 identity/status 不得覆盖当前左手设备状态；
- 无线时钟同步建议使用至少 1500 ms 超时，直连 S3 可使用 300 ms。

连续振动的固件新鲜度窗口约 150 ms。上位机建议每 100 ms 重发当前五路电平；超过窗口或连接断开时固件会自动停止。

## 8. TeleX Studio 最小功能界面

建议只保留：

- 触觉源连接状态；
- 五指实时压力值与矩阵；
- 单指/五指模式；
- 单指模式的手指选择；
- 启振阈值；
- 最大振幅，默认 AMP 47；
- 固定频率展示：168 Hz；
- 五路马达在线/故障掩码；
- 开始联动、停止/急停；
- 当前输出 `[CH0..CH4]`。

不同步：

- 关节角度/位置面板；
- 机械手姿态控制；
- 动作预设；
- 速度/力矩设置；
- 关节标定按钮。

## 9. 故障与安全处理

以下任一条件出现时立即发送全零或急停：

- 触觉源 `connected=false`；
- SSE/ROS 数据超过 500 ms 未更新；
- USB 串口断开；
- 时钟同步失败；
- 固件 ACK 超时；
- 用户切换设备或关闭联动；
- 校准期间固件报告 inhibit；
- 马达故障掩码非零。

不要在重连后自动恢复旧振幅；应等待一帧新的有效触觉数据后重新开始会话。

## 10. 验收清单

1. C6 能在 8 秒内收到约 240 个左手姿态/状态包，证明约 30 Hz 无线链路正常。
2. `motors=0x1f`，确认五路驱动在线。
3. 单指模式逐一验证五指物理对应关系。
4. 五指模式同时按压两根以上手指，对应马达同时响应。
5. AMP 47 单指满压力时，确认下发电平为 40。
6. 五指满压力时，确认总能量限制生效且无过流/故障。
7. 停止触觉数据后 150–500 ms 内全部停振。
8. C6 断开、左手掉电和应用退出时均无持续振动。
9. TeleX Studio 中不存在关节控制与动作预设入口。

## 11. 当前已知边界

- `0x1f` 只能证明五路驱动在线，不能替代线束对应实测。
- 多指满幅会触发能量预算缩放。
- 本同步包只负责触觉与振动，不承担机械手运动控制。
