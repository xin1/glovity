操作说明

阵列固定为与指尖传感器一致的 12 行 × 6 列。箭头方向由压力中心计算，局部压力越大箭头越亮、越长。先在右侧选择模式，再按压采集区触发；灵敏度越低，需要越大的压力才启振。默认、摩擦和长振均按住多久振动多久，松开即停；短振与碰撞松开后完成当前效果。
