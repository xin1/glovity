# 振动编辑器界面说明

## 界面与使用说明

| 模块       | 主要功能                                                     |
| ---------- | ------------------------------------------------------------ |
| 触觉采集   | 接收五指 `12 × 6` 压力矩阵                                   |
| 压力显示   | 显示 `0–15 N` 压力、曲线和峰值，实时曲线按 256 个层级平滑变化 |
| 空间解算   | 计算接触中心、合力方向和摩擦方向                             |
| 触觉识别   | 识别短振、长振、摩擦和碰撞                                   |
| 振动输出   | 压力同步映射到频率与振幅                                     |
| 参数设置   | 调整频率、振幅和反馈灵敏度                                   |
| F0 检测    | 检测当前指尖马达谐振频率                                     |
| 模拟测试   | 使用矩阵或曲线模拟连续压力输入                               |
| 机械手控制 | 控制 25 个关节和动作预设                                     |
| 软件标定   | 保存并恢复当前位置基准                                       |
| 状态诊断   | 显示 ROS2、ESP32 和串口状态                                  |
| 主题切换   | 支持日间与夜间界面                                           |

### 1. 启动与连接

1. 双击项目根目录的 `start-linkerhand-webui.bat`。

2. 浏览器会自动打开：

   `http://127.0.0.1:8765/`

3. 页面右上方显示 **“ROS2 数据流正常”** 后，即可查看 LinkerHand L20/L25 数据。

4. 如需控制 LRA，点击右侧 **“连接设备”**，选择 ESP32 对应的 COM 串口。

5. 等待设备状态显示就绪后再进行振动操作。

### 3. 实机模式与模拟输入

#### 实机模式

<img width="715" height="457" alt="3fd99c4ca0ced33a9ccd69506820a87a" src="https://github.com/user-attachments/assets/dfc10c32-86bd-449d-ab47-692df7b9b78d" />  

按钮显示 **“实机模式”** 时：

- 页面读取 LinkerHand 指尖传感器数据。
- 压力变化会映射为振动频率和振幅。
- 选中的指尖决定单指曲线、矩阵和 F0 检测通道。
- 实机压力超过灵敏度阈值后，连接的 LRA 才会输出振动。

#### 模拟输入

<img width="953" height="492" alt="image" src="https://github.com/user-attachments/assets/814af23e-30d0-4e5e-8a2c-a11d7314e8e2" />

点击 **“实机模式”** 可切换为 **“模拟输入”**。

模拟输入支持两种操作：

##### 点击压力曲线

- 点击或上下拖动曲线区域模拟 `0–15 N` 压力。
- 越靠上压力越大，越靠下压力越小。
- 压力变化采用平滑缓动，不会突然跳变。
- 长按时曲线持续向前更新。
- 松开后立即停止。

##### 点击采样区

- 按住采样矩阵模拟触觉接触。
- 拖动可以改变接触位置和合力方向。
- 长按会持续输入，即使鼠标不移动也会继续更新。
- 松开后立即停止并归零。

连接 ESP32 和 LRA 后，模拟压力也可以实际驱动振动；未连接时仅进行界面预览。

### 4. 振动模式

右侧可以手动选择振动效果；当识别到相应模式时会亮对应识别指示灯。下表参数以 `code/app.js` 和 `code/telex-device.js` 的 TELEX v1 实际发送逻辑为准。

| 模式 | 触发条件 | TELEX v1 频率 | 振幅 | 输出时长 |
|---|---|---:|---|---|
| 默认 | 压力超过当前灵敏度阈值 | 固定 `168 Hz` | 随压力变化，最大为整体 AMP | 按住多久振多久 |
| 短振 | 有效接触后单次触发 | 由固件短振预设决定，网页不下发频率 | 随触发压力变化，最大为整体 AMP | `18 ms`，`preset=0` |
| 长振 | 压力超过当前灵敏度阈值 | 固定 `168 Hz` | 持续随压力变化 | 按住多久振多久 |
| 摩擦 | 压力超过当前灵敏度阈值 | 固定 `168 Hz` | 持续随压力变化 | 按压期间持续输出 |
| 碰撞 | 输出门槛 `>=6 N`；自动识别灯门槛 `>10 N` | 由固件碰撞预设决定，网页不下发频率 | 随碰撞压力变化，最大为整体 AMP | `60 ms`，`preset=3` |

> TELEX v1 连续输出协议只发送五路马达电平，不发送频率。界面识别灯与实际输出模式是两套逻辑：识别灯亮起不会自动改变右侧当前选择的模式。

#### 默认

- 按住多久振动多久。
- TELEX v1 固定使用 `168 Hz`，压力只控制振幅。
- 轻压力输出较弱，重压力逐渐增加到当前设置的最大 AMP。

#### 短振

- 单次触力时触发。
- 用于表现短促点击或点按反馈。
- TELEX v1 使用 `preset=0`，实际请求时长为 `18 ms`。
- 网页不向短振命令发送可调频率；其波形频率由设备固件预设决定。
- 指示灯亮约 `0.5 秒`。

#### 长振

<img width="716" height="453" alt="d42f8e0bbbbcaf5c02a20612368f6ddd" src="https://github.com/user-attachments/assets/1d0c6ce7-f871-4487-9dc7-849fcb3033f8" />  

- 持续按压超过约 `0.5 秒`后识别。
- 按住期间持续亮灯和输出。
- TELEX v1 连续频率固定为 `168 Hz`，振幅随压力变化。

#### 摩擦

<img width="715" height="457" alt="3fd99c4ca0ced33a9ccd69506820a87a" src="https://github.com/user-attachments/assets/dfc10c32-86bd-449d-ab47-692df7b9b78d" />  

- 根据触觉压力中心的连续方向移动识别。
- 摩擦成立时，摩擦灯持续亮起。
- TELEX v1 连续频率固定为 `168 Hz`，振幅随压力变化。

#### 碰撞

<img width="716" height="458" alt="cb603dc5ceeea0e2fc517f7e5b379f8c" src="https://github.com/user-attachments/assets/eb8e6b24-8a13-49fc-911e-f2d97e554484" />  

- 初次接触压力超过 `10 N` 时，自动识别为碰撞并点亮指示灯。
- 当前实际碰撞输出代码允许在压力达到 `6 N` 后触发。
- TELEX v1 使用 `preset=3`，实际请求时长为 `60 ms`；波形频率由固件预设决定。
- 碰撞灯亮约 `0.5 秒`。

#### 自定义模式

页面预留了三个自定义模式：

- 自定义 1
- 自定义 2
- 自定义 3

目前显示为“暂未定义”。

#### 立即停止

点击 **“立即停止”**：

- 立即停止当前 LRA 输出。
- 结束正在进行的模拟输入。
- 不会改变当前的实机/模拟输入模式。

### 5. 输出参数

#### 整体频率

- 可调范围：`0–400 Hz`
- 建议范围：`50–300 Hz`
- 建议区间在滑块中以浅色区域显示。

该设置只对旧版串口振动板有效：压力较小时，代码从约 `94 Hz` 向设置的频率上限映射。

连接 TELEX v1 后，频率控件会被禁用，默认、长振和摩擦的连续输出固定为 `168 Hz`。短振和碰撞只发送固件预设编号、强度与时长，网页不下发其频率。

#### 整体振幅

- 可调范围：`AMP 0–75`
- 建议范围：`AMP 25–47`

压力越大，实际 AMP 越接近设定上限；轻压力会使用较低输出，以拉开轻触和重压之间的差异。

TELEX v1 的实际马达电平范围为 `0–40`：`AMP 25 → 18`、`AMP 47 → 40`，因此默认上限 `AMP 47` 已对应单路满幅。AMP 设置高于 47 时，TELEX v1 的实际输出仍封顶为 40。

修改后点击 **“应用到设备”**。

#### 反馈灵敏度

共有 `1–5` 档，默认使用：

- `5 · 高灵敏`

灵敏度越高，越小的压力变化也会产生反馈；灵敏度较低时，输出更稳定，但需要更大的压力变化。

### 7. 状态和故障判断

#### ESP32 未连接

触觉数据仍可显示，但 LRA 只能预览，不能实际振动。

#### 串口日志

串口日志会显示：

- 网页发送的控制命令
- ESP32 返回信息
- 模式启动与停止
- F0 检测结果
- 设备错误或超时

出现问题时可先查看此区域。
