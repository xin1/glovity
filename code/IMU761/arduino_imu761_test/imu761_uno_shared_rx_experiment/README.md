# 公共 RX 碰撞实验

这是按要求保留公共 RX 的实验程序。程序不发送查询指令，也不能安排两只 IMU 的发送顺序，只从收到的混合字节流中寻找 CRC 正确的 HI91 帧，再按地址 `01`、`02` 分类输出。

## 接线

```text
IMU 01 TX ── 支路隔离/限流 ──┐
                              ├── UNO D10
IMU 02 TX ── 支路隔离/限流 ──┘

所有 GND 共地
UNO D11 悬空
两只 IMU RX、SYNC_IN 均可不接
```

如果两个 IMU TX 是直接并联的推挽输出，每个 TX 支路至少串一个约 1kΩ 电阻限制输出相反时的电流。已有二极管隔离网络时按实际网络保留，并确保公共线静态高电平正确。不要把 UNO D11 接到 IMU。

两只 IMU均配置为 `9600`、HI91 自动输出。为了增加看到完整帧的机会，可先设为较低频率，例如逐只设置：

```text
LOG HI91 ONTIME 0.5
LOG ENABLE
SAVECONFIG
REBOOT
```

打开程序后，Arduino IDE 选择经典 Arduino Uno，上传并用 115200 打开串口监视器。

- `frames`：通过 CRC 且地址为 01/02 的帧数。
- `crc`：候选帧 CRC 错误数。
- `discard`：为了重新寻找帧头而丢弃的字节数。
- `overflow`：UNO 软件串口来不及处理的次数。
- `unknown_addr`：CRC 正确但地址不是 01/02 的帧数。

若两只输出始终同相重叠，`frames` 可能一直为 0。将两只设置成不同周期可能偶尔得到完整帧，但不能形成可靠通信。该程序仅用于观察实验现象。
