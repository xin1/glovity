# IMU761 地址配置工具 v2.0.0（主动查询版）

Windows 图形工具，适配瑞芬提供的 `68 04 地址 03 校验和` 查询命令。新固件不自动输出时，先查询当前地址，再修改并主动查询新地址验证，不再被动等待自动输出。

## 使用方法

1. 使用 3.3V USB-TTL：TX 接 IMU RXD1，RX 接 IMU TXD1，GND 共地。
2. 关闭其他占用同一 COM 口的串口助手、烧录器或 Arduino 串口监视器。
3. 启动 `dist/IMU761_Address_Tool.exe`（窗口显示 v2.0.0）。
4. 选择串口、波特率（默认115200），填写“查询地址”，例如 `0x01`，点击连接。工具自动发一次查询。
5. 不知道地址时点击“扫描未知地址”。优先扫描输入地址和00/01/02，再扫描剩余地址00–FE；找到有效的匹配回复即停止，完整扫描约2分钟，可随时停止。扫描不会修改地址，也不发送FF广播。
6. 当前地址由 CRC 正确且地址匹配的 HI91 回复确认后，选择新地址并点击“修改地址”。
7. 工具发送一次改址指令，然后每约0.6秒查询新地址，最多等待约5秒。仅收到新地址的有效HI91才提示成功，配置应答本身不算验证成功。
8. 修改后断电重启，用新地址再次查询，确认掉电保存。程序不发送未经确认的额外保存指令。

一次只连接一个 IMU，USB-TTL与模块直接交叉连接、正常供电并共地。波特率选择只改变电脑端，不修改IMU设置；若模块仍保存9600，选择9600。8数据位、无校验、1停止位。所有68命令均为二进制字节，不附加CRLF。

## 协议示例

| 操作 | HEX |
|---|---|
| 查询地址00 | `68 04 00 03 07` |
| 查询地址01 | `68 04 01 03 08` |
| 查询地址02 | `68 04 02 03 09` |
| 地址01改为02 | `68 05 01 0F 02 17` |

命令校验和：长度、地址、命令字和数据域求和取低8位，不含68帧头。改址命令沿用厂家提供的0F协议，查询使用新提供的03命令。

回复解析沿用已验证的新版/Wearable HI91布局：82字节，帧头5A A5、数据域76字节、标签91；整帧偏移10为地址；CRC-16多项式1021、初值0，覆盖帧头/长度和数据域，不含CRC字段。厂家新固件如改变回复格式，工具不会猜测并显示成功；请保留日志中的原始RX HEX供适配。

## 超时处理

- 查询超时：检查目标地址、实际波特率、USB-TTL TX→IMU RXD1及单机连接。界面会保留原始HEX；有数据不等于有效HI91。
- 修改结果未确认：可能改址已成功但回复未解析，先查询新/旧地址或扫描，不要盲目重复写入。工具清除旧的已确认地址以防继续对错误目标写入。
- RX应答校验错误不会影响改址状态。兼容厂家示例中8F应答按0F计算校验的写法，同时接受常规累加校验。
- 本工具用于单机配置，不是多机轮询采集器。修改前确保另一只IMU已断开，避免地址冲突或误判。

## 验证情况

协议与图形界面模拟串口测试覆盖查询命令、扫描、旧地址/错误地址回复过滤、修改后主动验证、失败应答、超时及损坏数据恢复。未自动访问真实COM口或修改实物地址；新固件实际回复仍需接机确认。

## 重新构建

在 PowerShell 中运行：

```powershell
.\build.ps1
```

依赖已经安装时可用 `.\build.ps1 -SkipInstall`。生成文件：`dist/IMU761_Address_Tool.exe`。EXE支持 `--self-test`，在隐藏窗口中验证UI初始化和查询指令，不连接串口。
