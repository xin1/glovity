# JY901P 新固件验收步骤

## 1. 测试准备

- 一次只连接一个待测 JY901P。
- 远离电机、扬声器、磁铁、钢制桌腿、大电流线缆和手机磁吸配件。
- 使用短线连接 VCC、GND、SDA、SCL，并保证 Arduino 与 IMU 共地。
- 将程序烧录后，把串口监视器设置为 115200 baud。
- 程序默认自动扫描地址。如总线上还有其他 I2C 设备，请把程序顶部的
  `FORCE_SENSOR_ADDRESS` 改成实际地址，例如 `0x50` 或 `0x55`。
- 启动信息必须出现 `100 Hz configuration: VERIFIED`。

## 2. 静止稳定性测试

1. 把 IMU 固定在水平、坚硬且不振动的非磁性平面上。
2. 上电后静置 30 秒，不要触碰。
3. 发送 `q`，继续静置 10 秒。
4. 保存 `RESULT,STATIC` 这一行。

建议工程筛选值（不是厂商规格承诺）：

- 水平安装时 `abs(roll_mean)`、`abs(pitch_mean)` 尽量不超过 1°～2°。
- `roll_std`、`pitch_std` 越小越好，通常应小于约 0.2°。
- `yaw_p2p` 越小越好；室内静止 10 秒若超过约 2°，应检查磁干扰或融合稳定性。
- `acc_norm_mean` 应接近 1 g。
- 三轴 `gyro*_mean` 应接近 0 dps；明显偏置应先做零偏/加速度校准。

## 3. Roll/Pitch 已知角度准确性

使用直角块、水平仪或带刻度的非磁性夹具，不要只用手估计角度。每个姿态稳定后发送对应命令，并等待 3 秒结果：

- `0`：Roll=0°，Pitch=0°。
- `1`：Roll=+90°，Pitch=0°。
- `2`：Roll=-90°，Pitch=0°。
- `3`：Roll=0°，Pitch=+90°。
- `4`：Roll=0°，Pitch=-90°。

记录每条 `RESULT,POSE` 中的 `roll_error`、`pitch_error` 和标准差。Pitch 接近 ±90°时存在欧拉角奇异性，程序会把 Roll 误差标记为 `NA_GIMBAL_LOCK`，此时只判断 Pitch。建议把可判定的主要角度误差控制在 1°～2°内；如果所有姿态都有相同固定偏差，先检查模块安装基准面和轴定义。

## 4. 官方磁力计校准

1. 在最终使用环境中发送 `m`。
2. 确认输出中的 `CALSW=7`，表示模块进入维特官方磁力计校准模式。
3. 两三分钟内缓慢、连续地绕三个轴旋转，覆盖尽可能多的方向；不要只在水平面画“8”字。
4. 若新固件支持 I2C 状态寄存器，输出会依次显示 25%、50%、75%、90%、100% 和质量值。
5. 质量达到 99% 或更高后发送 `e`。若质量不可用，也应完成充分的三轴覆盖后再发送 `e`。
6. 保存 `RESULT,MAG_SWEEP,name=CALIBRATION`。

`span_balance` 是本程序根据三轴磁场跨度计算的覆盖均衡度，不是维特官方质量值。越接近 100% 说明三个轴采集范围越均衡；明显低于约 70% 通常说明某个轴转动覆盖不足。

## 5. 校准后磁场覆盖测试

1. 校准结束后发送 `k`。
2. 在 30 秒内再次缓慢绕三个轴完整旋转。
3. 程序自动输出 `RESULT,MAG_SWEEP,name=POST_CAL`。
4. 检查三个轴的 span 是否接近、center 是否没有异常巨大偏置，以及 `span_balance` 是否较高。

此测试只能用于比较同一型号、同一环境下的模块和校准前后变化；它不能代替专业三轴亥姆霍兹线圈或转台标定。

## 6. 航向角准确性与复现性

使用非磁性转台，在纸上标出 0°、+90°、180°、-90°四个方向。整个测试中保持 IMU 水平，并远离金属：

1. 对准 0°标记，静止后发送 `z`，建立航向参考。
2. 顺时针或按模块正方向精确旋转 90°，静止后发送 `5`。
3. 转到 180°，静止后发送 `6`。
4. 转到 -90°，静止后发送 `7`。
5. 回到原始 0°标记，静止后发送 `8`。

查看 `RESULT,YAW` 的 `error`。作为普通室内工程筛选，可先采用增量误差不超过约 3°～5°、回到 0°后的误差不超过约 3°作为目标；这些是建议阈值，不是厂商保证指标。若误差随摆放位置明显变化，应优先排查环境磁场，而不是判定 IMU 固件有问题。

## 7. 对比新旧固件

在同一个夹具、同一位置、同一供电和相同测试顺序下分别测试旧固件与新固件，比较：

- 静止 Roll/Pitch/Yaw 标准差和峰峰值。
- 五个已知姿态的最大绝对误差。
- 四个航向角的最大绝对误差和回零误差。
- 官方磁校准质量。
- `span_balance` 和三轴中心偏置。

不要使用不同桌面、不同电缆位置或不同周边设备得到的数据直接比较固件。
