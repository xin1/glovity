# STM32F103C8T6 连接 MPU9250：姿态解算、校准、防漂移与 3D 对比

> 文档性质：硬件接线、STM32CubeIDE 配置、HAL 驱动、姿态融合与实验验证  
> 目标平台：STM32F103C8T6（Blue Pill 或最小系统板）+ MPU9250/MPU9255 模块  
> 软件环境：STM32CubeIDE + STM32CubeMX/HAL，PC 端 Python 3  
> 更新日期：2026-08-27

## 摘要

本文从零完成一套可验证的 MPU9250 姿态系统。STM32 通过 I²C 读取 MPU9250 内部的 MPU6500 加速度计/陀螺仪和 AK8963 磁力计；同一组数据同时送入两条算法链路：

- **未校准基线**：原始陀螺仪直接积分，不使用加速度计和磁力计纠偏；
- **校准防漂移链路**：陀螺仪零偏、加速度计六面、磁力计硬铁/软铁标定，然后使用带观测门控的 Mahony 9 轴融合。

STM32 经串口同时输出两组欧拉角，PC 端程序在同一窗口显示两个 3D 物体。因为两条链路使用的是同一时刻、同一次运动的数据，所以可以直观看到未校准姿态随时间漂移，而融合姿态在合理磁环境中回到重力和地磁参考。

必须先明确三个边界：

1. 本文解决的是**姿态漂移**，不是对加速度二次积分得到的位置漂移。仅靠消费级 IMU 无法长期得到无漂移位置。
2. 加速度计只能长期约束 roll/pitch；没有磁力计、视觉或其他绝对参考时，yaw 必然漂移。
3. 磁力计会受电机、磁铁、铁件和大电流导线干扰。错误地强制使用磁力计，可能比不使用更差，因此代码必须有磁场异常门控。

## 1. 硬件准备与接线

### 1.1 器件

- STM32F103C8T6 最小系统板；
- MPU9250 模块；
- ST-Link V2 或兼容调试器；
- 3.3 V USB-TTL 串口模块；
- 杜邦线；
- 可选：I²C 上拉电阻 2.2 kΩ～4.7 kΩ。

市场上标为“MPU9250”的模块可能实际装有 MPU9255、翻新芯片或兼容芯片。程序应读取身份寄存器，而不能只根据丝印判断：

| 器件 | 地址 | `WHO_AM_I` 寄存器 | 常见返回值 |
|---|---:|---:|---:|
| MPU9250 | `0x68/0x69` | `0x75` | `0x71` |
| MPU9255 | `0x68/0x69` | `0x75` | `0x73` |
| AK8963 | `0x0C` | `0x00` | `0x48` |

如果 MPU 身份正常而 AK8963 始终无应答，优先检查旁路模式、模块真伪和焊接，不要先怀疑姿态算法。

### 1.2 推荐接线

| STM32F103C8T6 | MPU9250 | 用途 |
|---|---|---|
| `3V3` | `VCC` | 3.3 V 供电 |
| `GND` | `GND` | 共地 |
| `PB6` | `SCL` | I²C1 时钟 |
| `PB7` | `SDA` | I²C1 数据 |
| `GND` | `AD0` | MPU 地址为 `0x68` |
| `PA0`（可选） | `INT` | 数据就绪外部中断 |
| `PA9` | USB-TTL RX | USART1 调试输出 |
| `PA10` | USB-TTL TX | USART1 接收，可选 |

注意事项：

- **推荐整块模块只接 3.3 V。** 某些 GY-9250 板带 3.3 V 稳压器，却不一定带 I²C 电平转换；接 5 V 后 SDA/SCL 上拉到 5 V 可能损坏 STM32。
- SDA、SCL 必须有上拉。很多模块已焊 4.7 kΩ～10 kΩ；线长、并联模块多或 400 kHz 通信不稳定时，换成约 2.2 kΩ～4.7 kΩ并缩短导线。
- I²C 地址由 AD0 决定：AD0 接地为 `0x68`，接 3.3 V 为 `0x69`。HAL API 使用左移一位后的地址，即 `0x68 << 1`。
- 面包板导线尽量短，传感器旁路电容不要省。电机和大电流线与磁力计保持距离。
- ST-Link 连接 `SWDIO(PA13)`、`SWCLK(PA14)`、GND 和参考电压；不要把 5 V 串口电平直接送入 STM32。

## 2. STM32CubeIDE / CubeMX 设置

以下配置以常见 8 MHz 外部晶振的 Blue Pill 为例。如果板上晶振不同，必须按实际频率修改。

### 2.1 新建工程

1. `File -> New -> STM32 Project`，选择 `STM32F103C8Tx`。
2. 在 `System Core -> SYS` 中将 Debug 设为 `Serial Wire`。
3. 在 `System Core -> RCC` 中启用 `High Speed Clock (HSE) -> Crystal/Ceramic Resonator`。

### 2.2 时钟树

在 `Clock Configuration` 中设置：

- HSE：8 MHz；
- PLL Source：HSE；
- PLL Mul：×9；
- SYSCLK/HCLK：72 MHz；
- APB1：36 MHz；
- APB2：72 MHz。

I²C1 在 APB1 上，不能因为 CPU 是 72 MHz 就把 APB1 也错误设成 72 MHz。

### 2.3 I²C1

在 `Connectivity -> I2C1` 中选择 `I2C`：

- PB6：I2C1_SCL；
- PB7：I2C1_SDA；
- Addressing Mode：7-bit；
- Clock Speed：先用 100 kHz 调通，再改 400 kHz；
- Duty Cycle：400 kHz 时可用 `I2C_DUTYCYCLE_2`。

如果总线偶发 `HAL_BUSY` 或 NACK，先降回 100 kHz、检查上拉和线长，而不是增加无限重试。

### 2.4 USART1

在 `Connectivity -> USART1` 中选择 `Asynchronous`：

- Baud rate：921600（线材或 USB-TTL 不稳定时用 460800）；
- Word length：8 bits；
- Parity：None；
- Stop bits：1；
- PA9：TX，PA10：RX。

100 Hz 输出一行对比数据时，115200 也可用，但不要打印过多原始调试字段。

### 2.5 TIM2 微秒计时

启用 `Timers -> TIM2 -> Clock Source: Internal Clock`：

- Prescaler：`72 - 1`；
- Counter Period：`0xFFFFFFFF`；
- Counter Mode：Up；
- 不需要中断。

这样 TIM2 每 1 μs 计数一次。程序启动后调用：

```c
HAL_TIM_Base_Start(&htim2);
```

姿态积分必须使用实测 `dt`，不能假设每次循环都恰好是 5 ms。

### 2.6 可选的 INT 数据就绪中断

把 PA0 配为 `GPIO_EXTI0`、Rising edge，打开 EXTI0 中断。中断回调只置位，不在中断中执行 I²C：

```c
volatile uint8_t imu_data_ready = 0;

void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
    if (GPIO_Pin == GPIO_PIN_0) {
        imu_data_ready = 1;
    }
}
```

初学阶段也可暂不接 INT，用 TIM2 控制约 200 Hz 读取。中断方案采样抖动更小。

### 2.7 生成代码

在 `Project Manager` 中勾选“为每个外设生成独立 `.c/.h` 文件”是可选项，然后生成工程。自定义代码必须放在 `USER CODE BEGIN/END` 区域内，否则重新生成代码会被覆盖。

## 3. 量程、采样率和数据流

本文使用以下折中配置：

| 项目 | 配置 | 换算系数 |
|---|---:|---:|
| 加速度计 | ±4 g | 8192 LSB/g |
| 陀螺仪 | ±500 °/s | 65.5 LSB/(°/s) |
| MPU 采样率 | 200 Hz | `1000 / (1 + 4)` |
| 陀螺 DLPF | 约 41 Hz | `CONFIG = 3` |
| 加速度 DLPF | 约 44.8 Hz | `ACCEL_CONFIG2 = 3` |
| 磁力计 | 100 Hz、16 bit | 约 0.1499 μT/LSB，再乘 ASA |
| 姿态更新 | 200 Hz | 磁数据无新值时仅用 accel + gyro |
| 串口显示 | 100 Hz | 每两个姿态周期输出一次 |

量程过小会饱和，过大会降低有效分辨率。手持姿态演示通常 ±4 g、±500 °/s 足够；快速机械运动应根据峰值调整，并同步修改换算系数。

数据链路如下：

```text
同一帧 MPU9250 原始数据
        ├── A：原始 gyro -> 四元数积分 -> 未校准姿态
        └── B：三类标定 -> 观测有效性判断 -> Mahony -> 防漂移姿态
                                                ↓
                         UART 同行输出 A、B -> PC 双 3D 对比
```

## 4. MPU9250 HAL 驱动

### 4.1 头文件 `mpu9250.h`

在工程的 `Core/Inc` 中创建 `mpu9250.h`：

```c
#ifndef MPU9250_H
#define MPU9250_H

#include "main.h"
#include <stdbool.h>

#define MPU9250_ADDR       (0x68u << 1)  // HAL 使用 8-bit 形式地址
#define AK8963_ADDR        (0x0Cu << 1)

typedef struct {
    float ax, ay, az;       // g
    float gx, gy, gz;       // deg/s
    float mx, my, mz;       // uT，已对齐到 accel/gyro 轴
    float temperature_c;
    bool  mag_valid;        // 本周期是否读到一帧有效新磁数据
} MPU9250_Data;

typedef struct {
    I2C_HandleTypeDef *i2c;
    float mag_asa[3];
    float last_mx, last_my, last_mz;
} MPU9250;

HAL_StatusTypeDef MPU9250_Init(MPU9250 *dev, I2C_HandleTypeDef *hi2c);
HAL_StatusTypeDef MPU9250_Read(MPU9250 *dev, MPU9250_Data *out);

#endif
```

### 4.2 实现文件 `mpu9250.c`

在 `Core/Src` 中创建 `mpu9250.c`：

```c
#include "mpu9250.h"
#include <string.h>

// MPU9250 registers
#define REG_SMPLRT_DIV      0x19
#define REG_CONFIG          0x1A
#define REG_GYRO_CONFIG     0x1B
#define REG_ACCEL_CONFIG    0x1C
#define REG_ACCEL_CONFIG2   0x1D
#define REG_INT_PIN_CFG     0x37
#define REG_INT_ENABLE      0x38
#define REG_ACCEL_XOUT_H    0x3B
#define REG_USER_CTRL       0x6A
#define REG_PWR_MGMT_1      0x6B
#define REG_PWR_MGMT_2      0x6C
#define REG_WHO_AM_I        0x75

// AK8963 registers
#define AK_REG_WIA          0x00
#define AK_REG_ST1          0x02
#define AK_REG_HXL          0x03
#define AK_REG_CNTL1        0x0A
#define AK_REG_ASAX         0x10

static HAL_StatusTypeDef write8(I2C_HandleTypeDef *i2c,
                                uint16_t addr, uint8_t reg, uint8_t value)
{
    return HAL_I2C_Mem_Write(i2c, addr, reg, I2C_MEMADD_SIZE_8BIT,
                             &value, 1, 100);
}

static HAL_StatusTypeDef readn(I2C_HandleTypeDef *i2c,
                               uint16_t addr, uint8_t reg,
                               uint8_t *data, uint16_t len)
{
    return HAL_I2C_Mem_Read(i2c, addr, reg, I2C_MEMADD_SIZE_8BIT,
                            data, len, 100);
}

static int16_t be16(const uint8_t *p)
{
    return (int16_t)(((uint16_t)p[0] << 8) | p[1]);
}

static int16_t le16(const uint8_t *p)
{
    return (int16_t)(((uint16_t)p[1] << 8) | p[0]);
}

HAL_StatusTypeDef MPU9250_Init(MPU9250 *dev, I2C_HandleTypeDef *hi2c)
{
    uint8_t who = 0;
    uint8_t asa[3];
    memset(dev, 0, sizeof(*dev));
    dev->i2c = hi2c;

    if (HAL_I2C_IsDeviceReady(hi2c, MPU9250_ADDR, 3, 100) != HAL_OK)
        return HAL_ERROR;
    if (readn(hi2c, MPU9250_ADDR, REG_WHO_AM_I, &who, 1) != HAL_OK)
        return HAL_ERROR;
    if (who != 0x71 && who != 0x73)
        return HAL_ERROR;

    // 器件复位；复位后需等待内部时钟和寄存器稳定
    if (write8(hi2c, MPU9250_ADDR, REG_PWR_MGMT_1, 0x80) != HAL_OK)
        return HAL_ERROR;
    HAL_Delay(100);

    // CLKSEL=1：使用陀螺 X 轴 PLL；唤醒全部 6 轴
    if (write8(hi2c, MPU9250_ADDR, REG_PWR_MGMT_1, 0x01) != HAL_OK)
        return HAL_ERROR;
    if (write8(hi2c, MPU9250_ADDR, REG_PWR_MGMT_2, 0x00) != HAL_OK)
        return HAL_ERROR;
    HAL_Delay(10);

    // 1 kHz / (1 + 4) = 200 Hz；DLPF 约 41/44.8 Hz
    if (write8(hi2c, MPU9250_ADDR, REG_SMPLRT_DIV, 4) != HAL_OK)
        return HAL_ERROR;
    if (write8(hi2c, MPU9250_ADDR, REG_CONFIG, 0x03) != HAL_OK)
        return HAL_ERROR;
    if (write8(hi2c, MPU9250_ADDR, REG_GYRO_CONFIG, 0x08) != HAL_OK) // ±500 dps
        return HAL_ERROR;
    if (write8(hi2c, MPU9250_ADDR, REG_ACCEL_CONFIG, 0x08) != HAL_OK) // ±4 g
        return HAL_ERROR;
    if (write8(hi2c, MPU9250_ADDR, REG_ACCEL_CONFIG2, 0x03) != HAL_OK)
        return HAL_ERROR;

    // 关闭 MPU 内部 I2C master，并让主 MCU 直接访问内部 AK8963
    if (write8(hi2c, MPU9250_ADDR, REG_USER_CTRL, 0x00) != HAL_OK)
        return HAL_ERROR;
    if (write8(hi2c, MPU9250_ADDR, REG_INT_PIN_CFG, 0x02) != HAL_OK) // BYPASS_EN
        return HAL_ERROR;
    if (write8(hi2c, MPU9250_ADDR, REG_INT_ENABLE, 0x01) != HAL_OK) // DATA_RDY
        return HAL_ERROR;
    HAL_Delay(10);

    if (HAL_I2C_IsDeviceReady(hi2c, AK8963_ADDR, 3, 100) != HAL_OK)
        return HAL_ERROR;
    if (readn(hi2c, AK8963_ADDR, AK_REG_WIA, &who, 1) != HAL_OK || who != 0x48)
        return HAL_ERROR;

    // AK8963 必须先 Power-down，再进入 Fuse ROM 模式读取灵敏度调整值
    if (write8(hi2c, AK8963_ADDR, AK_REG_CNTL1, 0x00) != HAL_OK)
        return HAL_ERROR;
    HAL_Delay(10);
    if (write8(hi2c, AK8963_ADDR, AK_REG_CNTL1, 0x0F) != HAL_OK)
        return HAL_ERROR;
    HAL_Delay(10);
    if (readn(hi2c, AK8963_ADDR, AK_REG_ASAX, asa, 3) != HAL_OK)
        return HAL_ERROR;
    for (int i = 0; i < 3; ++i)
        dev->mag_asa[i] = ((float)asa[i] - 128.0f) / 256.0f + 1.0f;

    // 先退出 Fuse ROM，再进入 16-bit、100 Hz 连续测量模式 2
    if (write8(hi2c, AK8963_ADDR, AK_REG_CNTL1, 0x00) != HAL_OK)
        return HAL_ERROR;
    HAL_Delay(10);
    if (write8(hi2c, AK8963_ADDR, AK_REG_CNTL1, 0x16) != HAL_OK)
        return HAL_ERROR;
    HAL_Delay(10);

    return HAL_OK;
}

HAL_StatusTypeDef MPU9250_Read(MPU9250 *dev, MPU9250_Data *out)
{
    uint8_t b[14];
    uint8_t st1;
    const float a_scale = 1.0f / 8192.0f;
    const float g_scale = 1.0f / 65.5f;
    const float m_scale = 4912.0f / 32760.0f; // uT/LSB

    if (readn(dev->i2c, MPU9250_ADDR, REG_ACCEL_XOUT_H, b, 14) != HAL_OK)
        return HAL_ERROR;

    out->ax = (float)be16(&b[0])  * a_scale;
    out->ay = (float)be16(&b[2])  * a_scale;
    out->az = (float)be16(&b[4])  * a_scale;
    out->temperature_c = (float)be16(&b[6]) / 333.87f + 21.0f;
    out->gx = (float)be16(&b[8])  * g_scale;
    out->gy = (float)be16(&b[10]) * g_scale;
    out->gz = (float)be16(&b[12]) * g_scale;
    out->mag_valid = false;

    if (readn(dev->i2c, AK8963_ADDR, AK_REG_ST1, &st1, 1) == HAL_OK &&
        (st1 & 0x01u)) {
        uint8_t mb[7]; // HXL..HZH + ST2；读取 ST2 才会释放本帧
        if (readn(dev->i2c, AK8963_ADDR, AK_REG_HXL, mb, 7) == HAL_OK) {
            if ((mb[6] & 0x08u) == 0) { // HOFL=0：没有磁传感器溢出
                float nx = (float)le16(&mb[0]) * m_scale * dev->mag_asa[0];
                float ny = (float)le16(&mb[2]) * m_scale * dev->mag_asa[1];
                float nz = (float)le16(&mb[4]) * m_scale * dev->mag_asa[2];

                // 裸 MPU9250 芯片中 AK8963 与 accel/gyro 轴不完全同向。
                // 常见芯片坐标映射为 [Mx,My,Mz]body=[My,Mx,-Mz]native。
                // 必须用转板实验核对自己的模块丝印方向；不一致就在此修改。
                out->mx = ny;
                out->my = nx;
                out->mz = -nz;
                dev->last_mx = out->mx;
                dev->last_my = out->my;
                dev->last_mz = out->mz;
                out->mag_valid = true;
            }
        }
    }

    // AK8963 是 100 Hz，而主循环是 200 Hz。无新数据时保留最近值，
    // 但 mag_valid=false，融合器本周期不重复施加同一磁观测。
    if (!out->mag_valid) {
        out->mx = dev->last_mx;
        out->my = dev->last_my;
        out->mz = dev->last_mz;
    }
    return HAL_OK;
}
```

### 4.3 驱动中最容易忽略的细节

1. MPU 加速度和陀螺数据是大端，AK8963 磁数据是小端。
2. 读取磁数据时必须一直读到 `ST2`；否则 AK8963 可能不更新下一帧。
3. `ST2.HOFL=1` 表示磁数据溢出，本帧必须丢弃。
4. AK8963 的 ASA 是每颗芯片独有的灵敏度调整值，不能固定写成 1。
5. 磁力计轴必须映射到加速度计/陀螺仪坐标系。若轴交换或符号错，静止时 roll/pitch 可能正常，但 yaw 会反转或随倾斜变化。
6. 不能在 200 Hz 主循环中强迫 100 Hz 磁力计每次产生新数据；要检查 `DRDY`。

## 5. 三类标定

标定顺序应为：先统一坐标轴，再标定传感器，最后调整融合参数。否则标定参数与实际输入轴不对应。

### 5.1 标定结构与应用函数

```c
typedef struct {
    float gyro_bias[3];       // deg/s
    float accel_bias[3];      // g
    float accel_scale[3];     // dimensionless
    float mag_offset[3];      // uT，硬铁偏置
    float mag_softiron[3][3]; // 软铁校正矩阵
} IMU_Calibration;

static void mat3_mul_vec(const float m[3][3], const float v[3], float o[3])
{
    for (int r = 0; r < 3; ++r)
        o[r] = m[r][0] * v[0] + m[r][1] * v[1] + m[r][2] * v[2];
}

static void apply_calibration(const MPU9250_Data *raw,
                              const IMU_Calibration *c,
                              MPU9250_Data *v)
{
    *v = *raw;
    v->gx = raw->gx - c->gyro_bias[0];
    v->gy = raw->gy - c->gyro_bias[1];
    v->gz = raw->gz - c->gyro_bias[2];

    v->ax = (raw->ax - c->accel_bias[0]) * c->accel_scale[0];
    v->ay = (raw->ay - c->accel_bias[1]) * c->accel_scale[1];
    v->az = (raw->az - c->accel_bias[2]) * c->accel_scale[2];

    float m0[3] = {
        raw->mx - c->mag_offset[0],
        raw->my - c->mag_offset[1],
        raw->mz - c->mag_offset[2]
    };
    float mc[3];
    mat3_mul_vec(c->mag_softiron, m0, mc);
    v->mx = mc[0]; v->my = mc[1]; v->mz = mc[2];
}
```

初次运行时可先使用单位参数：

```c
static IMU_Calibration cal = {
    .gyro_bias = {0, 0, 0},
    .accel_bias = {0, 0, 0},
    .accel_scale = {1, 1, 1},
    .mag_offset = {0, 0, 0},
    .mag_softiron = {
        {1, 0, 0},
        {0, 1, 0},
        {0, 0, 1}
    }
};
```

### 5.2 陀螺仪上电零偏

让模块固定在最终安装位置，远离振动并静置 5～10 秒。丢掉前 200 帧启动瞬态，再平均约 2000 帧：

```c
bool calibrate_gyro(MPU9250 *imu, float bias[3])
{
    MPU9250_Data s;
    double sum[3] = {0, 0, 0};
    double sum2[3] = {0, 0, 0};
    const int discard = 200;
    const int count = 2000;

    for (int i = 0; i < discard; ++i) {
        if (MPU9250_Read(imu, &s) != HAL_OK) return false;
        HAL_Delay(5);
    }
    for (int i = 0; i < count; ++i) {
        if (MPU9250_Read(imu, &s) != HAL_OK) return false;
        float g[3] = {s.gx, s.gy, s.gz};
        for (int k = 0; k < 3; ++k) {
            sum[k] += g[k];
            sum2[k] += (double)g[k] * g[k];
        }
        HAL_Delay(5);
    }

    for (int k = 0; k < 3; ++k) {
        bias[k] = (float)(sum[k] / count);
        double var = sum2[k] / count - (double)bias[k] * bias[k];
        if (var > 0.25) return false; // 标准差 >0.5 dps，标定期间很可能动了
    }
    return true;
}
```

关键不是“平均次数越多越好”，而是标定期间必须真正静止。陀螺零偏还会随温度变化，所以应记录标定温度；温差较大的产品需做温度—零偏曲线。

### 5.3 加速度计六面标定

分别让 +X、-X、+Y、-Y、+Z、-Z 竖直向上，每个姿态静置并取均值。对每一轴：

$$
b_i=\frac{a_{i,+}+a_{i,-}}{2},\qquad
s_i=\frac{2}{a_{i,+}-a_{i,-}}
$$

```c
void accel_six_face_axis(float positive_g, float negative_g,
                         float *bias_g, float *scale)
{
    *bias_g = 0.5f * (positive_g + negative_g);
    *scale  = 2.0f / (positive_g - negative_g);
}
```

例如 X 正向平均值 `+1.018 g`、X 反向平均值 `-0.982 g`：

```text
X bias  = (1.018 + -0.982) / 2 = 0.018 g
X scale = 2 / (1.018 - -0.982) = 1.000
```

每个面采样时，非重力轴应接近 0，合加速度模长应接近 1 g。桌面不水平会污染结果，可用直角块固定模块。

### 5.4 磁力计标定

磁力计必须在最终装配状态下标定。让设备绕所有轴缓慢转动，覆盖尽可能多的空间方向，记录每轴最大最小值。简化的硬铁 + 对角软铁标定为：

```c
void mag_minmax_finish(const float minv[3], const float maxv[3],
                       float offset[3], float softiron[3][3])
{
    float radius[3];
    float avg_radius;
    for (int i = 0; i < 3; ++i) {
        offset[i] = 0.5f * (maxv[i] + minv[i]);
        radius[i] = 0.5f * (maxv[i] - minv[i]);
    }
    avg_radius = (radius[0] + radius[1] + radius[2]) / 3.0f;
    for (int r = 0; r < 3; ++r)
        for (int c = 0; c < 3; ++c)
            softiron[r][c] = (r == c) ? avg_radius / radius[r] : 0.0f;
}
```

采集循环：

```c
float minv[3] = { 1e9f, 1e9f, 1e9f};
float maxv[3] = {-1e9f,-1e9f,-1e9f};

// 在约 30~60 秒内持续翻滚设备
if (raw.mag_valid) {
    float m[3] = {raw.mx, raw.my, raw.mz};
    for (int i = 0; i < 3; ++i) {
        if (m[i] < minv[i]) minv[i] = m[i];
        if (m[i] > maxv[i]) maxv[i] = m[i];
    }
}
```

最大最小法只能修正轴向偏置和缩放。点云若是旋转的椭球，应在 PC 上做完整椭球拟合，得到 3×3 软铁矩阵。判断标定质量的方法不是只看欧拉角，而是看校正后磁场模长：设备任意旋转时应大致恒定。

### 5.5 参数保存

实验阶段可把结果填回 `cal` 常量。产品中应保存到 Flash，并同时保存：

- 版本号和校验和；

## 6. 防漂移核心：四元数、门控与 Mahony 融合

### 6.1 漂移从哪里来

纯陀螺积分为：

$$
\theta(t)=\theta(0)+\int_0^t(\omega+ b_g+n_g)\,dt
$$

即使 Z 轴只有 `0.2 °/s` 零偏，一分钟也会累计约 `12°` 航向误差。减去启动零偏只能消除一部分固定误差，温漂和随机误差仍存在。Mahony 融合用当前姿态预测重力/地磁方向，再用测量方向与预测方向的叉积产生反馈：

$$
\boldsymbol\omega_c=\boldsymbol\omega_m-\mathbf b_g
+K_p\mathbf e+K_i\int\mathbf e\,dt
$$

- 比例项 `Kp` 快速把姿态拉回参考；
- 积分项 `Ki` 缓慢估计残余陀螺偏置；
- 加速度异常时停止重力纠偏；
- 磁场异常时停止航向纠偏；
- 所有积分都使用实测 `dt`，并对异常时间间隔限幅。

### 6.3 `attitude.c`

```c
#include "attitude.h"
#include <math.h>

#define RAD2DEG 57.2957795131f

static float clampf(float x, float lo, float hi)
{
    return x < lo ? lo : (x > hi ? hi : x);
}

static void normalize_q(float *q0, float *q1, float *q2, float *q3)
{
    float n2 = (*q0)*(*q0) + (*q1)*(*q1) + (*q2)*(*q2) + (*q3)*(*q3);
    if (n2 < 1e-12f) {
        *q0 = 1; *q1 = *q2 = *q3 = 0;
        return;
    }
    float inv = 1.0f / sqrtf(n2);
    *q0 *= inv; *q1 *= inv; *q2 *= inv; *q3 *= inv;
}

static void integrate_q(float *q0, float *q1, float *q2, float *q3,
                        float gx, float gy, float gz, float dt)
{
    float a = *q0, b = *q1, c = *q2, d = *q3;
    float half_dt = 0.5f * dt;
    *q0 += (-b*gx - c*gy - d*gz) * half_dt;
    *q1 += ( a*gx + c*gz - d*gy) * half_dt;
    *q2 += ( a*gy - b*gz + d*gx) * half_dt;
    *q3 += ( a*gz + b*gy - c*gx) * half_dt;
    normalize_q(q0, q1, q2, q3);
}

void GyroOnly_Init(GyroOnlyAHRS *s)
{
    s->q0 = 1; s->q1 = s->q2 = s->q3 = 0;
}

void GyroOnly_Update(GyroOnlyAHRS *s,
                     float gx, float gy, float gz, float dt)
{
    integrate_q(&s->q0, &s->q1, &s->q2, &s->q3, gx, gy, gz, dt);
}

void Mahony_Init(MahonyAHRS *s, float kp, float ki)
{
    s->q0 = 1; s->q1 = s->q2 = s->q3 = 0;
    s->integral_x = s->integral_y = s->integral_z = 0;
    s->kp = kp;
    s->ki = ki;
    s->mag_norm_ref = 0;
    s->mag_ref_ready = false;
}

void Mahony_Update(MahonyAHRS *s,
                   float gx, float gy, float gz,
                   float ax, float ay, float az,
                   float mx, float my, float mz,
                   bool mag_new, float dt)
{
    if (!(dt > 0.0005f && dt < 0.03f)) return; // 拒绝断点/阻塞造成的异常 dt

    float an = sqrtf(ax*ax + ay*ay + az*az);
    bool acc_ok = an > 0.85f && an < 1.15f;    // 动态加速度门控
    if (acc_ok) { ax /= an; ay /= an; az /= an; }

    float mn = sqrtf(mx*mx + my*my + mz*mz);
    bool mag_ok = mag_new && mn > 5.0f && mn < 100.0f;
    if (mag_ok && !s->mag_ref_ready) {
        s->mag_norm_ref = mn;
        s->mag_ref_ready = true;
    }
    if (mag_ok && s->mag_ref_ready) {
        float ratio = mn / s->mag_norm_ref;
        mag_ok = ratio > 0.70f && ratio < 1.30f;
    }
    if (mag_ok) {
        // 只有已通过门控的样本才缓慢更新环境磁场模长参考
        s->mag_norm_ref = 0.999f * s->mag_norm_ref + 0.001f * mn;
        mx /= mn; my /= mn; mz /= mn;
    }

    float q0=s->q0, q1=s->q1, q2=s->q2, q3=s->q3;
    float ex=0, ey=0, ez=0;
    bool correction = false;

    if (acc_ok) {
        // 当前四元数预测出的 body 系重力方向（省略公共因子 2）
        float vx = q1*q3 - q0*q2;
        float vy = q0*q1 + q2*q3;
        float vz = q0*q0 - 0.5f + q3*q3;
        ex += ay*vz - az*vy;
        ey += az*vx - ax*vz;
        ez += ax*vy - ay*vx;
        correction = true;
    }

    if (mag_ok) {
        // 把实测磁场旋转到世界系，求世界系水平/竖直参考 bx、bz
        float hx = 2.0f*(mx*(0.5f-q2*q2-q3*q3)
                         + my*(q1*q2-q0*q3) + mz*(q1*q3+q0*q2));
        float hy = 2.0f*(mx*(q1*q2+q0*q3)
                         + my*(0.5f-q1*q1-q3*q3) + mz*(q2*q3-q0*q1));
        float hz = 2.0f*(mx*(q1*q3-q0*q2)
                         + my*(q2*q3+q0*q1) + mz*(0.5f-q1*q1-q2*q2));
        float bx = sqrtf(hx*hx + hy*hy);
        float bz = hz;

        // 世界磁参考 [bx,0,bz] 旋回 body 系后的预测方向
        float wx = bx*(0.5f-q2*q2-q3*q3) + bz*(q1*q3-q0*q2);
        float wy = bx*(q1*q2-q0*q3)       + bz*(q0*q1+q2*q3);
        float wz = bx*(q0*q2+q1*q3)       + bz*(0.5f-q1*q1-q2*q2);
        ex += my*wz - mz*wy;
        ey += mz*wx - mx*wz;
        ez += mx*wy - my*wx;
        correction = true;
    }

    if (correction) {
        s->integral_x += s->ki * ex * dt;
        s->integral_y += s->ki * ey * dt;
        s->integral_z += s->ki * ez * dt;
        // 防止长时间错误观测导致积分饱和，单位 rad/s
        s->integral_x = clampf(s->integral_x, -0.10f, 0.10f);
        s->integral_y = clampf(s->integral_y, -0.10f, 0.10f);
        s->integral_z = clampf(s->integral_z, -0.10f, 0.10f);
        gx += s->kp*ex + s->integral_x;
        gy += s->kp*ey + s->integral_y;
        gz += s->kp*ez + s->integral_z;
    }

    integrate_q(&s->q0, &s->q1, &s->q2, &s->q3, gx, gy, gz, dt);
}

void Quaternion_ToEuler(float q0, float q1, float q2, float q3,
                        float *roll, float *pitch, float *yaw)
{
    float sinp = 2.0f * (q0*q2 - q3*q1);
    *roll  = atan2f(2.0f*(q0*q1 + q2*q3),
                    1.0f - 2.0f*(q1*q1 + q2*q2)) * RAD2DEG;
    *pitch = asinf(clampf(sinp, -1.0f, 1.0f)) * RAD2DEG;
    *yaw   = atan2f(2.0f*(q0*q3 + q1*q2),
                    1.0f - 2.0f*(q2*q2 + q3*q3)) * RAD2DEG;
}
```

### 6.4 为什么这些代码能抑制漂移

#### 四元数归一化

浮点积分会使四元数逐渐偏离单位长度。每次积分后归一化，防止旋转矩阵产生缩放和非正交误差。它只能修复数值约束，不能消除传感器零偏。

#### 加速度门控

静止时加速度计主要观测重力；快速平移时还包含运动加速度。代码只在模长位于 `0.85～1.15 g` 时使用重力纠偏，避免急甩时把线性加速度误认为倾角。阈值应根据设备振动实测调整。

#### 磁场门控

代码先限制绝对磁场模长，再与缓慢更新的环境参考比较。超出参考 `70%～130%` 的样本不参与航向修正。此方法能拒绝明显干扰，但无法识别“模长相近、方向错误”的磁场，严谨产品还应比较磁倾角、创新量和连续性。

#### 积分抗饱和

`Ki` 用于跟踪残余陀螺偏置。如果异常观测持续存在，积分项可能越来越大；因此将其限制在 ±0.10 rad/s。更稳妥的策略是在观测持续异常时缓慢衰减积分项。

#### 实测 dt

串口输出、I²C 重试和中断都会使循环周期波动。固定写死 `dt=0.005` 会把时序误差直接积成角度误差。TIM2 的微秒计数相减使用无符号整数，计数器回绕时仍能正确得到小于一个回绕周期的差值。

### 6.5 参数怎么调

建议从 `Kp=2.0`、`Ki=0.05` 开始：

- 静止回正太慢：增大 `Kp`；
- 振动时姿态抖：减小 `Kp`，或收紧加速度门控并改善机械减振；
- 放置数分钟仍缓慢漂：确认标定和磁数据正确后，小幅增大 `Ki`；
- 航向突然跳：先排查磁干扰、坐标映射和磁标定，不要直接减小所有增益；
- 快速运动跟随慢：检查 DLPF、输出率和量程是否合适。

调参必须先确保传感器单位、轴方向、`dt` 和标定正确。滤波器无法修复错误输入。

主循环：

```c
uint32_t previous_us = micros32();
uint32_t next_sample_us = previous_us;
uint32_t frame = 0;

while (1)
{
    uint32_t now = micros32();
    if ((int32_t)(now - next_sample_us) < 0)
        continue;
    next_sample_us += 5000u; // 200 Hz；不会把执行时间重复加进周期

    float dt = safe_dt(now, previous_us);
    previous_us = now;

    MPU9250_Data raw, corrected;
    if (MPU9250_Read(&imu, &raw) != HAL_OK)
        continue;
    apply_calibration(&raw, &cal, &corrected);

    const float d2r = 0.0174532925199f;

    // A 路故意使用未减零偏的原始 gyro，且完全没有重力/磁场纠偏
    GyroOnly_Update(&raw_att,
                    raw.gx*d2r, raw.gy*d2r, raw.gz*d2r, dt);

    // B 路使用标定数据 + 加速度/磁力计异常门控 + Mahony 反馈
    Mahony_Update(&fused_att,
                  corrected.gx*d2r, corrected.gy*d2r, corrected.gz*d2r,
                  corrected.ax, corrected.ay, corrected.az,
                  corrected.mx, corrected.my, corrected.mz,
                  corrected.mag_valid, dt);

    if ((frame++ & 1u) == 0u) { // 100 Hz 串口输出
        float rr,rp,ry, fr,fp,fy;
        Quaternion_ToEuler(raw_att.q0, raw_att.q1, raw_att.q2, raw_att.q3,
                           &rr,&rp,&ry);
        Quaternion_ToEuler(fused_att.q0, fused_att.q1, fused_att.q2, fused_att.q3,
                           &fr,&fp,&fy);
        float an = sqrtf(corrected.ax*corrected.ax +
                         corrected.ay*corrected.ay + corrected.az*corrected.az);
        int acc_ok = an > 0.85f && an < 1.15f;

        char line[180];
        int n = snprintf(line, sizeof(line),
            "CMP,%lu,%.3f,%.3f,%.3f,%.3f,%.3f,%.3f,%d,%d\r\n",
            HAL_GetTick(), rr,rp,ry, fr,fp,fy,
            acc_ok, corrected.mag_valid ? 1 : 0);
        if (n > 0)
            HAL_UART_Transmit(&huart1, (uint8_t *)line,
                              (uint16_t)((n < sizeof(line)) ? n : sizeof(line)-1), 20);
    }
}
```

### 7.1 为什么比较是公平的

- 两条链路读取同一个 `raw`，不存在两次动作不同的问题；
- 两条链路使用相同 `dt`；
- 初始四元数相同；
- 唯一差别是是否使用标定和绝对参考纠偏。

注意：B 路启动时的 yaw 零点由世界磁北方向决定，A 路零点是上电时的相对方向。比较重点应是“静置后是否持续漂”和“运动后能否回到稳定姿态”，而不是要求两者绝对 yaw 初值完全相同。

这份最小代码从单位四元数启动。演示时应让模块在上电阶段保持水平且 X 轴朝预定方向；若设备允许任意姿态上电，应先用首批静态加速度和磁力计数据计算初始 roll/pitch/yaw，再构造初始四元数，以缩短融合器收敛过程。

```python
                line = ser.readline().decode("ascii", errors="ignore").strip()
                p = line.split(",")
                if len(p) != 10 or p[0] != "CMP":
                    continue
                sample = {
                    "t": int(p[1]) * 0.001,
                    "raw": tuple(map(float, p[2:5])),
                    "fused": tuple(map(float, p[5:8])),
                    "acc_ok": int(p[8]),
                    "mag_new": int(p[9]),
                }
                with lock:
                    latest = sample
            except (ValueError, serial.SerialException):
                continue


def euler_matrix(roll, pitch, yaw):
    """与 STM32 输出约定一致：R = Rz(yaw) @ Ry(pitch) @ Rx(roll)。"""
    r, p, y = np.deg2rad([roll, pitch, yaw])
    cr, sr = np.cos(r), np.sin(r)
    cp, sp = np.cos(p), np.sin(p)
    cy, sy = np.cos(y), np.sin(y)
    rx = np.array([[1,0,0], [0,cr,-sr], [0,sr,cr]])
    ry = np.array([[cp,0,sp], [0,1,0], [-sp,0,cp]])
    rz = np.array([[cy,-sy,0], [sy,cy,0], [0,0,1]])
    return rz @ ry @ rx


BASE_VERTICES = np.array([
    [-1.4,-0.8,-0.25], [ 1.4,-0.8,-0.25],
    [ 1.4, 0.8,-0.25], [-1.4, 0.8,-0.25],
    [-1.4,-0.8, 0.25], [ 1.4,-0.8, 0.25],
    [ 1.4, 0.8, 0.25], [-1.4, 0.8, 0.25],
])
FACES = [[0,1,2,3], [4,5,6,7], [0,1,5,4],
         [2,3,7,6], [1,2,6,5], [0,3,7,4]]


def setup_box_axis(ax, title):
    ax.set_xlim(-2, 2); ax.set_ylim(-2, 2); ax.set_zlim(-2, 2)
    ax.set_box_aspect((1, 1, 1))
    ax.set_xlabel("X"); ax.set_ylabel("Y"); ax.set_zlabel("Z")
    ax.set_title(title)


def draw_box(ax, angles, color, title):
    ax.cla()
    setup_box_axis(ax, title)
    rotated = BASE_VERTICES @ euler_matrix(*angles).T
    polys = [[rotated[i] for i in f] for f in FACES]
    ax.add_collection3d(Poly3DCollection(
        polys, facecolors=color, edgecolors="black", alpha=0.72))
    # 物体 X 轴画成红色箭头，便于观察 yaw
    origin = np.zeros(3)
    direction = euler_matrix(*angles) @ np.array([1.8, 0, 0])
    ax.quiver(*origin, *direction, color="red", linewidth=2)
    ax.text2D(0.02, 0.02,
              f"R={angles[0]:7.2f}  P={angles[1]:7.2f}  Y={angles[2]:7.2f}",
              transform=ax.transAxes)


fig = plt.figure(figsize=(13, 8))
ax_raw = fig.add_subplot(2, 2, 1, projection="3d")
ax_fused = fig.add_subplot(2, 2, 2, projection="3d")
ax_curve = fig.add_subplot(2, 1, 2)


def update(_):
    with lock:
        s = None if latest is None else dict(latest)
    if s is None:
        return

    draw_box(ax_raw, s["raw"], "tab:red", "未校准：原始陀螺积分")
    draw_box(ax_fused, s["fused"], "tab:green", "已校准：Mahony 防漂移")

    history_t.append(s["t"])
    history_raw_yaw.append(s["raw"][2])
    history_fused_yaw.append(s["fused"][2])
    t0 = history_t[0]
    ts = np.array(history_t) - t0

    ax_curve.cla()
    ax_curve.plot(ts, history_raw_yaw, color="tab:red", label="raw yaw")
    ax_curve.plot(ts, history_fused_yaw, color="tab:green", label="fused yaw")
    ax_curve.set_title(
        f"Yaw 对比（acc_ok={s['acc_ok']}, mag_new={s['mag_new']}）")
    ax_curve.set_xlabel("time / s")
    ax_curve.set_ylabel("yaw / deg")
    ax_curve.grid(True, alpha=0.3)
    ax_curve.legend(loc="upper left")
    fig.tight_layout()


threading.Thread(target=serial_worker, daemon=True).start()
ani = FuncAnimation(fig, update, interval=30, cache_frame_data=False)
plt.show()
```

## 9. 实验步骤与预期数据

### 9.1 上电静置漂移实验

1. 传感器固定不动，预热约 1 分钟。
2. 重新上电并保持静止 5～10 分钟。
3. 保存串口 `CMP` 数据。
4. 分别计算两条链路 yaw 的线性斜率和峰峰值。

预期趋势示例（仅表示合理现象，不是本硬件实测保证值）：

| 指标（静置 10 min） | 未校准原始积分 | 校准 + Mahony |
|---|---:|---:|
| yaw 累计变化 | 数度到数十度 | 正常磁环境下通常显著更小 |
| roll/pitch 长期变化 | 持续缓慢漂 | 被重力方向约束 |
| 靠近磁铁时 yaw | 不受磁铁瞬时拉动，但继续积分漂 | 门控有效时短时转为惯导，离开后恢复 |

不要把示例数值写进实验结论。必须根据自己的 CSV 统计真实均值、标准差、峰峰值和漂移率。

### 9.2 90° 往返实验

1. 保持水平，绕 Z 轴转约 +90°，停 5 秒，再转回起点。
2. 重复 10 次。
3. 观察每次回到机械起点时两条 yaw 曲线的残差。

未校准积分的回零误差会逐步累积；标定融合链路应在地磁环境稳定时回到接近相同航向。若融合 yaw 随 roll/pitch 明显变化，通常是磁力计轴映射、硬软铁标定或旋转约定错误。

### 9.3 动态门控实验

- 快速前后平移但尽量不转动，观察 `acc_ok` 是否暂时变为 0；
- 将小磁铁逐渐靠近，观察磁融合被拒绝时 yaw 是否保持短时连续；
- 移除干扰后，航向应平滑恢复，而不是产生巨大跳变。

当前串口只输出 `mag_new`，它表示磁力计有新帧，不等于“磁场一定通过全部门控”。若要精确验证，可让 `Mahony_Update` 返回位标志并输出 `mag_used`。

### 9.4 离线计算漂移率

把串口文本保存成 `compare.csv` 后，可以用以下脚本估算首尾变化和线性漂移率：

```python
import numpy as np

rows = []
with open("compare.csv", "r", encoding="utf-8") as f:
    for line in f:
        p = line.strip().split(",")
        if len(p) == 10 and p[0] == "CMP":
            rows.append([float(x) for x in p[1:8]])

a = np.asarray(rows)
t = (a[:, 0] - a[0, 0]) / 1000.0
for name, yaw in [("raw", a[:, 3]), ("fused", a[:, 6])]:
    # 处理 -180/180 跳变后再拟合
    y = np.rad2deg(np.unwrap(np.deg2rad(yaw)))
    slope, intercept = np.polyfit(t, y, 1)
    print(f"{name:6s}: change={y[-1]-y[0]:8.3f} deg, "
          f"drift={slope*60:8.3f} deg/min, std={np.std(y):8.3f} deg")
```

## 10. 常见故障排查

| 现象 | 主要原因 | 检查方法 |
|---|---|---|
| MPU 无应答 | 地址、供电、上拉、焊接错误 | 扫描 `0x68/0x69`，示波器看 SCL/SDA |
| MPU 正常、AK8963 无应答 | 未开 bypass、假模块、磁芯片损坏 | 检查 `USER_CTRL=0`、`INT_PIN_CFG.BYPASS_EN=1` |
| I²C 一直 `HAL_BUSY` | SDA 被拉低、上次事务未结束 | 断电复位传感器；必要时启动前用 GPIO 输出 9 个 SCL 脉冲恢复总线 |
| 加速度静止不是约 1 g | 量程换算错误或轴数据拼接错误 | 核对 `ACCEL_CONFIG` 和 8192 LSB/g |
| 陀螺转动方向反了 | 坐标约定或模块安装方向不一致 | 单轴正向旋转逐轴验证 |
| roll/pitch 正常，yaw 很怪 | 磁轴映射、标定或磁干扰错误 | 画磁点云并做倾斜测试 |
| 静止仍缓慢漂 | 零偏/温漂、`dt` 错、`Ki` 太小 | 打印 gyro 均值、TIM2 周期和温度 |
| 快甩时姿态被拉歪 | 动态加速度参与了重力纠偏 | 收紧门控、改善 DLPF/机械减振 |
| yaw 周期跳 ±360° | 欧拉角显示包角 | 绘图时 `unwrap`，内部继续使用四元数 |
| 串口拖慢采样 | 阻塞发送或输出太多 | 降输出率、DMA 环形缓冲、二进制协议 |
| `printf` 无浮点 | newlib-nano 未打开浮点格式 | 添加 `-u _printf_float` |

### 10.1 I²C 扫描辅助代码

调驱动前可先扫描总线：

```c
char msg[32];
for (uint16_t a = 1; a < 128; ++a) {
    if (HAL_I2C_IsDeviceReady(&hi2c1, a << 1, 2, 20) == HAL_OK) {
        int n = snprintf(msg, sizeof(msg), "I2C:0x%02X\r\n", a);
        HAL_UART_Transmit(&huart1, (uint8_t *)msg, n, 100);
    }
}
```

正常旁路状态应看到 `0x68`（或 `0x69`）和 `0x0C`。

## 11. 从学习代码到可靠工程

本文代码适合学习和原型验证。继续工程化时建议按优先级增加：

1. I²C 超时统计、总线恢复和有限次数重试；
2. INT 驱动采样，UART DMA 环形缓冲，避免阻塞；
3. 完整磁力计椭球标定和标定参数 Flash 管理；
4. 静止检测后才允许在线微调 gyro bias，避免把缓慢真实运动学成零偏；
5. 磁场方向创新门控，而不只检查模长；
6. 温度—陀螺零偏模型；
7. 用逻辑分析仪、转台和长时间日志量化采样抖动、噪声和漂移；
8. 对每个失败分支记录错误码，而不是统一进入死循环。

若系统附近长期存在电机或铁磁结构，应考虑只用 6 轴融合稳定 roll/pitch，并用视觉、编码器、UWB 或其他外部观测约束 yaw。磁力计不是任何环境下都可靠的“绝对方向”。
